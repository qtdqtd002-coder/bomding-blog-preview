코드 두 개, 뭘 받나요

CHAMP10N·HAJ1MAR1G1FT, 코드별로 뭘 주나요

두 코드는 주는 보상이 완전히 달라요. 둘 다 게임 안 메뉴에서 직접 입력하는 방식이고, 결제나 별도 응모는 필요 없어요. 자세한 입력 절차는 아래에서 순서대로 안내할게요.

CHAMP10N괴력몬(노가드 특성 개체)~2026.08.31

CHAMP10N

CHAMP10N 코드로 받는 괴력몬

CHAMP10N 코드를 입력하면 노가드 특성이 붙은 괴력몬을 받아요. 노가드는 포켓몬 시리즈에서 서로의 기술이 명중률·회피율과 상관없이 그대로 맞는 특성이라, 격투 타입인 괴력몬한테 붙으면 확실하게 맞히는 쪽으로 굴리기 좋은 조합이거든요.

이 코드는 특정 인원만 한정으로 받는 게 아니라, 8월 31일까지는 기간 안에 언제든 입력할 수 있는 범용 코드로 보도됐어요. 계정당 딱 한 번만 열려 있는 코드가 아니라는 뜻이니, 지금 당장 안 넣었다고 조급해할 필요는 없어요.

💙 연의 한마디
짚어보면 CHAMP10N은 노가드 괴력몬 + 8월 31일까지 계속 열려 있는 범용 코드인데요, 서두르지 않아도 되지만 입력 자체를 미뤄둘 이유도 딱히 없으니 생각날 때 바로 넣어두면 돼요.

HAJ1MAR1G1FT

HAJ1MAR1G1FT는 패스트 쿠폰 100개예요

HAJ1MAR1G1FT 코드를 입력하면 패스트 쿠폰(Quick Coupon) 100개를 받는데요, 대기 시간을 줄이거나 렌탈·트레이닝 같은 데 쓰는 재화거든요.

이 코드를 검색하면 '패스트 티켓 리롤권'을 준다는 설명도 종종 보이는데요, 국내외 여러 매체를 같이 확인해보니 실제 보상은 패스트 쿠폰 100개로 일관되게 나오더라고요. 코드를 넣기 전에 헷갈리지 않게 짚어둘게요.

🩷 봄의 한마디
이 두 코드는 한국닌텐도 공식 SNS 발표를 게임톡 같은 국내 매체가 전했고, 해외 매체들도 같은 코드를 다 함께 소개하고 있더라고요. 다만 마감 시각까지 초 단위로 확정된 건 아니라서, 8월 31일이 다 됐다면 여유 부리지 말고 미리 넣어두는 게 마음 편해요.

받는 법

이상한 소포에서 코드 입력하는 법

코드는 게임 메인 화면의 서브메뉴에서 '이상한 소포' 메뉴로 들어가 입력해요. 정확히는 화면 우측 하단의 서브메뉴를 열고, 목록을 아래로 스크롤해서 이상한 소포를 찾으면 돼요. 순서대로 정리하면 이래요.

순서할 일
1단계메인 화면 우측 하단의 서브메뉴를 연다
2단계목록을 아래로 스크롤해 '이상한 소포' 메뉴를 찾는다
3단계코드·암호 입력란에 CHAMP10N 또는 HAJ1MAR1G1FT를 입력하고 확인한다
4단계선물함(메일박스)에서 보상을 수령한다

실제 '이상한 소포' 코드 입력 화면은 아니고, 참고용으로 실은 챔피언스 공식 전투 연출 컷이에요

이미지: 포켓몬 챔피언스 공식(자산 재사용)

받는 곳 UI가 헷갈리면 라이츄나이트 배포 때 정리해둔 포켓몬 챔피언스 라이츄나이트 획득 방법 글의 선물함 단계별 스크린샷을 참고해도 좋아요. 이번 코드는 그 선물함에 들어가기 전, '이상한 소포' 메뉴에서 코드를 직접 입력하는 절차가 하나 더 붙는다는 점이 달라요. 참고로 CHAMP10N·HAJ1MAR1G1FT처럼 이상한 소포에 넣는 문자열은, 팀 세팅을 통째로 복사하는 '렌탈팀 코드'와는 완전히 다른 계열이에요. 렌탈팀 코드 모음 글에서도 이 둘을 따로 구분해뒀는데, 이상한 소포에 코드를 직접 넣는 절차는 이번 글에서 처음 정리해봐요.

💙 연의 한마디
코드는 대소문자를 구분하고, 숫자 0이 알파벳 O로 잘못 입력되는 경우가 많더라고요. 그래서 직접 타이핑하기보다 복사해서 붙여넣는 걸 추천해요. 이상한 소포 메뉴는 튜토리얼을 다 깨고 메인 챔피언스 화면까지 들어가야 열리니까, 막 시작한 신규 세이브에서는 아직 안 보일 수 있어요.
🩷 봄의 한마디로 정리
정리하면 CHAMP10N은 노가드 괴력몬을 주고 패스트 쿠폰 100개는 HAJ1MAR1G1FT 쪽인데, 둘 다 8월 31일까지 서브메뉴의 이상한 소포에서 받을 수 있어요. 코드는 복사해서 붙여넣으면 실수할 일도 없으니, 생각났을 때 가볍게 챙겨두세요.
