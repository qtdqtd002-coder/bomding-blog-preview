클로드 아티팩트 공유하는 법 (Claude Artifacts)

하루살이2026.08.11· IT

클로드 아티팩트로 만든 화면이나 문서를, 대화 밖에서 공유해 보신 적 있나요? 그런데 그 링크를 받은 사람이 바로 고쳐 쓸 수 있는지, 게시 해제 버튼을 눌러도 되는 버튼인지는 다들 헷갈려 하세요.

결과부터 말하면 링크를 받은 사람이 그 자리에서 바로 고치는 remix 기능은 폐지됐어요. remix는 남의 아티팩트를 그 자리에서 커스터마이즈하던 기능이었어요. 지금은 코드를 복사해서 새 대화에 붙여넣는 방식으로만 독립 버전을 만들 수 있어요.

발행 자체에도 조건이 있어요. Code execution and file creation 설정이 꺼져 있으면 아티팩트를 새로 발행할 수 없어요. 그리고 게시 해제는 한 번 누르면 되돌릴 수 없는 버튼이라, 누르기 전에 한 번 더 생각해야 해요.

이번 글에서는 발행 절차부터 remix 폐지, 임베드, 게시 해제까지 순서대로 정리했어요. 아티팩트가 데스크톱·웹에서 보이는지는 지난 글에서 다뤘어요. 그 글은 코워크 확인법을 다룬 글이에요. 이번엔 발행 이후 단계만 다룰게요. 2026년 8월 11일 기준으로 확인했어요.

클로드 아티팩트, 어떻게 발행하나요?

클로드 아티팩트는 아티팩트 화면에서 Publish를 눌러 공개 링크를 복사하면 발행돼요.

단, 그 전에 Settings > Capabilities의 Code execution and file creation이 켜져 있어야 해요.

아티팩트 발행 기능을 만든 앤스로픽(Anthropic)의 공식 로고예요.

이미지 출처: anthropic.com 공식 로고 이미지

이 설정은 Settings > Capabilities 메뉴에 있어요. 요금제에 따라 위치가 달라요 — Free·Pro·Max는 개인 계정 설정에서 켜고, Team·Enterprise는 조직 설정에서 켜요.

공식 도움말에는 이렇게 적혀 있어요.

"We no longer support artifacts without Code execution and file creation enabled in Settings > Capabilities."

우리말로 옮기면, Code execution and file creation을 켜지 않은 아티팩트는 더 이상 지원하지 않는다는 뜻이에요. (Claude 공식 도움말 기준)

  1. 아티팩트 화면으로 이동해요.
  2. 발행하려는 아티팩트가 맞는 버전인지 확인해요.
  3. 화면에서 Publish를 클릭해요.
  4. 뜨는 공개 링크를 복사해요.

절차 자체는 네 단계뿐이라 어렵지 않아요. 다만 Code execution and file creation이 꺼져 있으면 이 단계를 시작할 수조차 없어요.

발행한 아티팩트, 링크만 보내면 상대가 바로 고칠 수 있나요?

발행한 아티팩트는 링크를 받은 사람이 그 자리에서 바로 고칠 수 없어요.

예전에는 남이 발행한 아티팩트를 그 자리에서 커스터마이즈하는 remix 기능이 있었지만, 지금은 폐지됐어요.

대신 발행된 아티팩트의 코드를 복사해서 새 대화에 붙여넣는 방식으로 독립 버전을 만들어요.

🔀remix 폐지 → 코드 복사 방식
발행된 아티팩트 화면에는 이제 그 자리에서 고치는 remix 버튼이 없어요. 복사한 코드는 새 대화 창에 붙여 넣으면 독립 버전이 나와요. 자세한 안내는 클로드 공식 도움말에서 볼 수 있어요.

지금은 이 방식으로만 독립 버전을 만들 수 있어요.

이렇게 만든 새 버전은 원본과 분리돼요. 원본 아티팩트가 나중에 바뀌어도 내가 복사해서 만든 버전은 그대로 남아요.

게시 해제하면 다시 발행할 수 있나요?

아니요, 한 번 게시 해제한 아티팩트는 같은 아티팩트를 다시 발행할 수 없어요.

공식 도움말 원문은 이렇게 적혀 있어요.

"Once you unpublish an artifact, you cannot publish that same artifact again."

우리말로 옮기면, 아티팩트를 게시 해제하면 그 아티팩트는 다시 발행할 수 없다는 뜻이에요. (Claude 공식 도움말 기준)

선택같은 아티팩트로 다시 발행
발행 상태 유지별도 조치 없이 계속 가능
게시 해제(unpublish)불가능해요
다시 공유하고 싶다면처음부터 새 아티팩트를 만들어야 해요

게시 해제 전에 한 번 더 생각하세요
버튼 하나 잘못 눌렀다가 되돌릴 수 없어요. 그 아티팩트로 다시 링크를 공유하고 싶다면, 처음부터 새로 만들어서 다시 발행해야 해요.

공식 도움말에는 저장 데이터 조항도 있어요. 그 아티팩트가 지속 저장(persistent storage) 기능을 썼다면, 게시 해제할 때 저장된 데이터(개인용·공유용 모두)도 함께 영구 삭제돼요.

발행된 아티팩트, 계정 없는 사람도 볼 수 있나요?

네, 회원가입하지 않은 사람도 발행된 아티팩트를 보고 사용할 수 있어요.

링크만 있으면 클로드 계정이 없어도 그 화면을 열어 볼 수 있어요.

따로 로그인 화면을 거치지 않는다는 뜻이에요. 이 점 때문에 발행 링크는 클로드를 안 쓰는 사람에게 결과물만 보여줄 때도 쓸 수 있어요.

다른 웹사이트에 아티팩트를 넣고 싶다면?

발행 후 뜨는 Get embed code 버튼으로 임베드 코드를 받으면 다른 사이트에도 넣을 수 있어요.

이때 Allowed domains 필드에 아티팩트를 넣을 도메인을 지정해야 해요. 도메인이 여러 개면 쉼표로 구분해서 넣으면 돼요.

🧩Get embed code → Allowed domains 지정
발행된 아티팩트 화면에서 Get embed code를 누르면 임베드용 코드가 나와요. Allowed domains 필드에 아티팩트를 넣을 도메인을 입력해야 해요. 자세한 안내는 클로드 공식 도움말에서 볼 수 있어요.

임베드 코드를 받은 뒤 이 필드를 꼭 채워야 해요.

도메인을 지정하지 않으면 원하는 곳에 제대로 심어지지 않을 수 있어요. 임베드까지 계획하고 있다면 이 필드를 빈칸으로 두지 않는 게 안전해요.

회사(Team·Enterprise) 계정으로 만들면 다르게 동작하나요?

네, Team·Enterprise 계정에서 만든 아티팩트는 공개 발행이 안 되고 조직 내부 공유만 가능해요.

이 아티팩트를 보려는 사람도 그 조직의 자격증명으로 로그인해야 볼 수 있어요.

그래서 회사 계정으로 작업 중이라면, 링크를 사내에서만 돌리는 용도로 써야 해요. 외부 사람에게 공개 링크로 보여주려는 목적이라면 개인 Free·Pro·Max 계정에서 발행하는 방식이 맞아요.

자주 묻는 질문

Q. 발행한 아티팩트는 나중에 어디서 다시 찾을 수 있나요?
A. 발행하면 그 아티팩트가 사이드바의 아티팩트 목록에도 함께 추가돼요. 처음 나눈 대화를 벗어나서도 거기서 다시 찾을 수 있어요.

Q. 임베드한 아티팩트도 로그인 없이 볼 수 있나요?
A. 일반 발행 아티팩트라면 임베드해도 로그인 없이 볼 수 있어요. Team·Enterprise 아티팩트는 공개 발행 자체가 안 되고, 임베드 코드는 발행 이후에 나오는 기능이에요. 조직 아티팩트를 다른 사이트에 심는 방법은 공식 안내에서 확인되지 않았어요.

다시 공유하고 싶다면처음부터 새 아티팩트를 만들어야 해요

게시 해제 전에 한 번 더 생각하세요
버튼 하나 잘못 눌렀다가 되돌릴 수 없어요. 그 아티팩트로 다시 링크를 공유하고 싶다면, 처음부터 새로 만들어서 다시 발행해야 해요.

공식 도움말에는 저장 데이터 조항도 있어요. 그 아티팩트가 지속 저장(persistent storage) 기능을 썼다면, 게시 해제할 때 저장된 데이터(개인용·공유용 모두)도 함께 영구 삭제돼요.

 

 

발행된 아티팩트, 계정 없는 사람도 볼 수 있나요?

네, 회원가입하지 않은 사람도 발행된 아티팩트를 보고 사용할 수 있어요.

링크만 있으면 클로드 계정이 없어도 그 화면을 열어 볼 수 있어요.

따로 로그인 화면을 거치지 않는다는 뜻이에요. 이 점 때문에 발행 링크는 클로드를 안 쓰는 사람에게 결과물만 보여줄 때도 쓸 수 있어요.

 

 

다른 웹사이트에 아티팩트를 넣고 싶다면?

발행 후 뜨는 Get embed code 버튼으로 임베드 코드를 받으면 다른 사이트에도 넣을 수 있어요.

이때 Allowed domains 필드에 아티팩트를 넣을 도메인을 지정해야 해요. 도메인이 여러 개면 쉼표로 구분해서 넣으면 돼요.

 

📷 〔사진 자리 2〕 발행된 아티팩트 화면의 Get embed code 버튼과 Allowed domains 입력 필드 — 클로드 아티팩트 화면에서 직접 캡처해 업로드

 

임베드 코드를 받은 뒤 이 필드를 꼭 채워야 해요.

도메인을 지정하지 않으면 원하는 곳에 제대로 심어지지 않을 수 있어요. 임베드까지 계획하고 있다면 이 필드를 빈칸으로 두지 않는 게 안전해요.

 

 

회사(Team·Enterprise) 계정으로 만들면 다르게 동작하나요?

네, Team·Enterprise 계정에서 만든 아티팩트는 공개 발행이 안 되고 조직 내부 공유만 가능해요.

이 아티팩트를 보려는 사람도 그 조직의 자격증명으로 로그인해야 볼 수 있어요.

그래서 회사 계정으로 작업 중이라면, 링크를 사내에서만 돌리는 용도로 써야 해요. 외부 사람에게 공개 링크로 보여주려는 목적이라면 개인 Free·Pro·Max 계정에서 발행하는 방식이 맞아요.

 

 

자주 묻는 질문

Q. 발행한 아티팩트는 나중에 어디서 다시 찾을 수 있나요?
A. 발행하면 그 아티팩트가 사이드바의 아티팩트 목록에도 함께 추가돼요. 처음 나눈 대화를 벗어나서도 거기서 다시 찾을 수 있어요.

Q. 임베드한 아티팩트도 로그인 없이 볼 수 있나요?
A. 일반 발행 아티팩트라면 임베드해도 로그인 없이 볼 수 있어요. Team·Enterprise 아티팩트는 공개 발행 자체가 안 되고, 임베드 코드는 발행 이후에 나오는 기능이에요. 조직 아티팩트를 다른 사이트에 심는 방법은 공식 안내에서 확인되지 않았어요.

하루 정리
발행은 Code execution and file creation을 켜고, 아티팩트 화면에서 Publish 누르고, 링크만 복사하면 끝나요.
링크만 보낸다고 상대가 바로 고칠 수 있는 건 아니에요. 복사한 코드를 새 대화에 붙이면 독립 버전이 나와요.
게시 해제는 되돌릴 수 없어요. 그 아티팩트를 다시 공유하고 싶다면 처음부터 새로 만들어야 해요.
개인 계정으로 외부에 공개하려면 발행을 쓰고, 회사 계정으로 사내에만 돌리려면 Team·Enterprise의 내부 공유를 쓰면 돼요.
