AI 쓰는 법

클로드 프로젝트 지식 영역 활용법 — 자료 다시 설명 안 해도 되게 (Claude Projects)

하루살이2026.08.05· IT

클로드 프로젝트(Projects) 지식 영역(project knowledge)에 자료를 이미 올려놨는데, 새 채팅을 열 때마다 같은 배경 설명을 처음부터 다시 치고 있나요. 자료를 올리는 방법은 알아도, 올린 자료를 실제로 계속 잘 써먹는 방법은 따로 있어요.

이 글은 지난번 다룬 「클로드 초기설정과 활용법」에서 프로젝트 만드는 법과 개수·용량 규정을 짚은 다음 칸이에요. 만드는 절차, Add to project, 무료·프로 개수, 파일 형식과 용량 한도는 그 글에서 다뤘으니 여기서는 다시 설명하지 않을게요. 이 글은 지식 영역에 자료를 올린 다음 그걸 굴리는 운영법만 다뤄요. 클로드 기능은 자주 바뀌는 영역이라 아래 내용은 2026년 8월 5일 기준이에요.

지식 영역엔 뭘 올려야 하나요

자주 안 바뀌는 참조 자료를 올리는 게 맞아요.

공식 문서는 지식 영역에 문서·텍스트·코드를 올려 클로드가 맥락을 더 잘 이해하게 만든다고 설명해요. 매번 값이 바뀌는 정보는 지식 영역보다 그때그때 채팅에 직접 넣는 편이 안전해요.

  • 프로젝트에서 자주 참조하는 문서·텍스트·코드
  • 스타일 가이드, 용어집처럼 웬만해선 안 바뀌는 자료
  • 매번 값이 바뀌는 정보는 지식 영역 대신 채팅에 직접

예전 파일을 그대로 두면 최신 파일과 함께 검색 대상이 될 수 있어요. 내용이 바뀐 자료는 새로 올리거나 예전 파일을 지워서 정리해 두는 편이 안전해요.

30MB 한도, 넘기지 않고 굴리는 법

파일 하나는 30MB 밑으로 맞추고, 자료 전체가 늘어나는 부분은 RAG라는 자동 검색 기능에 맡기면 돼요.

RAG는 검색 증강 생성을 뜻해요. 공식 문서는 프로젝트가 컨텍스트 한도에 가까워지면 RAG가 자동으로 켜진다고 밝혀요.

"RAG automatically activates when your project approaches or exceeds the context window limits."

RAG가 켜지면 프로젝트에 담을 수 있는 자료 용량이 최대 10배 늘어나고, 응답 정확도는 그대로 유지된다고 공식 문서에 나와요. 사용자가 켜고 끄는 설정이 아니라 조건이 되면 자동으로 켜지는 방식이에요.

그래서 파일 하나가 30MB를 넘길 것 같으면 여러 파일로 쪼개서 올리는 편이 나아요. 자료가 많아지는 부분은 RAG가 알아서 관련 있는 조각만 찾아 쓰니까요.

상태파일당 한도프로젝트 전체 용량
RAG 켜지기 전30MB컨텍스트 한도까지
RAG 켜진 뒤(자동)30MB(동일)최대 10배로 확장

매번 설명 반복 안 해도 되는 장치가 있나요

네, 프로젝트 지침이라는 기능이 그 역할을 해요.

공식 버튼 이름은 Set project instructions예요.

"Click on 'Set project instructions.'"

이렇게 저장한 지침은 그 프로젝트 안의 모든 채팅에 적용된다고 공식 문서에 나와 있어요. 새 채팅마다 말투나 배경 설명을 반복해서 치는 대신, 지침에 한 번 적어두면 그다음 채팅부터는 따로 안 써도 돼요.

프로젝트, 몇 개로 나눠야 하나요

성격이 다른 작업이면 프로젝트를 나누는 편이 나아요.

공식 문서는 이렇게 설명해요. "Each project has its own separate memory space and dedicated project summary, so the context within each of your projects is focused, relevant, and separate from other projects or non-project chats."

프로젝트마다 메모리 공간과 요약이 따로 관리된다는 뜻이에요. 성격이 다른 작업을 한 프로젝트에 몰아넣으면 메모리와 지식 영역 검색 결과에 관계없는 내용이 섞일 수 있어요. 업무 자료와 개인 학습 자료처럼 결이 다르면 프로젝트를 나눠 관리하는 편이 검색 정확도에 유리해요.

상황프로젝트 구성
성격 같은 작업만 있음프로젝트 1개로 모아도 됨
업무·개인처럼 성격이 다름프로젝트를 나눠서 관리(메모리·검색이 프로젝트별로 격리되기 때문)

채팅 검색·메모리랑 지식 영역, 뭐가 다른가요

지식 영역은 내가 직접 올린 자료를 찾고, 채팅 검색과 메모리는 예전 대화 내용을 찾는다는 점이 달라요.

역할을 표로 정리하면 이래요.

기능무엇을 찾나적용 범위·플랜
지식 영역내가 올린 문서·텍스트·코드프로젝트 안 모든 채팅, 전 플랜
메모리예전 대화 맥락프로젝트별로 분리(무료·Pro·Max 새 메모리 기준)
채팅 검색예전 대화 자체프로젝트 안으로 한정, 프로·맥스·팀·엔터프라이즈

공식 문서는 채팅 검색 범위를 이렇게 적어요. "Individual project conversations (searches are limited to within each specific project)"

메모리·채팅 검색 모두 지식 영역처럼 프로젝트 범위를 안 넘어가요. 다만 채팅 검색은 유료 플랜 전용이고, 메모리는 무료 플랜에도 포함돼요.

자료를 올렸는데 반영이 안 될 때, 뭘 먼저 봐야 하나요

가장 흔한 원인은 대화창에 첨부한 파일과 지식 영역에 올린 파일을 헷갈리는 경우예요.

지난 글에서 다룬 것처럼, 같은 프로젝트 안이라도 채팅끼리 내용이 자동 공유되지 않고 지식 영역 자료만 모든 채팅에서 함께 쓰여요. 파일을 대화창에만 첨부하고 지식 영역엔 안 올렸다면, 그 채팅에서만 보이고 다른 채팅에서는 안 보여요.

자료를 다시 올리면 바로 반영되는지처럼 구체적 해결 절차는 위에서 참고한 다섯 개 공식 문서 어디에도 안 나와 있어요. 그러니 먼저 확인할 건 그 파일이 대화창 첨부 목록에만 있는 건 아닌지, 지식 영역에 실제로 올라가 있는지부터예요.

자주 묻는 질문

Q. 지식 영역에는 이미지도 올릴 수 있나요?
네, 지난 글에서 다룬 파일 형식에 JPEG·PNG·GIF·WebP 이미지 형식도 포함돼 있다고 안내했어요.

Q. 지식 영역 자료를 다른 사람과 같이 볼 수 있나요?
개인 무료·프로·맥스 플랜엔 그런 공유 기능이 없고, 여러 명이 자료를 보고 수정하는 기능은 팀·엔터프라이즈 전용이라고 지난 글에서 다뤘어요.

Q. 지식 영역 자료가 많아지면 클로드 응답이 느려지나요?
공식 문서엔 속도 얘기는 따로 없고, RAG가 켜져도 응답 정확도는 그대로 유지된다고만 나와 있어요. 속도에 관한 확인된 내용은 없어서 단정하지 않을게요.

채팅 검색예전 대화 자체프로젝트 안으로 한정, 프로·맥스·팀·엔터프라이즈

공식 문서는 채팅 검색 범위를 이렇게 적어요. "Individual project conversations (searches are limited to within each specific project)"

메모리·채팅 검색 모두 지식 영역처럼 프로젝트 범위를 안 넘어가요. 다만 채팅 검색은 유료 플랜 전용이고, 메모리는 무료 플랜에도 포함돼요.

 

 

자료를 올렸는데 반영이 안 될 때, 뭘 먼저 봐야 하나요

가장 흔한 원인은 대화창에 첨부한 파일과 지식 영역에 올린 파일을 헷갈리는 경우예요.

지난 글에서 다룬 것처럼, 같은 프로젝트 안이라도 채팅끼리 내용이 자동 공유되지 않고 지식 영역 자료만 모든 채팅에서 함께 쓰여요. 파일을 대화창에만 첨부하고 지식 영역엔 안 올렸다면, 그 채팅에서만 보이고 다른 채팅에서는 안 보여요.

자료를 다시 올리면 바로 반영되는지처럼 구체적 해결 절차는 위에서 참고한 다섯 개 공식 문서 어디에도 안 나와 있어요. 그러니 먼저 확인할 건 그 파일이 대화창 첨부 목록에만 있는 건 아닌지, 지식 영역에 실제로 올라가 있는지부터예요.

 

 

자주 묻는 질문

Q. 지식 영역에는 이미지도 올릴 수 있나요?
네, 지난 글에서 다룬 파일 형식에 JPEG·PNG·GIF·WebP 이미지 형식도 포함돼 있다고 안내했어요.

Q. 지식 영역 자료를 다른 사람과 같이 볼 수 있나요?
개인 무료·프로·맥스 플랜엔 그런 공유 기능이 없고, 여러 명이 자료를 보고 수정하는 기능은 팀·엔터프라이즈 전용이라고 지난 글에서 다뤘어요.

Q. 지식 영역 자료가 많아지면 클로드 응답이 느려지나요?
공식 문서엔 속도 얘기는 따로 없고, RAG가 켜져도 응답 정확도는 그대로 유지된다고만 나와 있어요. 속도에 관한 확인된 내용은 없어서 단정하지 않을게요.
