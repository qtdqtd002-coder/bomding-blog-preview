GPT-5.6 Sol·Terra·Luna 차이 정리 — GPT-5.5랑 뭐가 다른가요

하루살이2026.07.23· IT

OpenAI가 2026년 7월 9일 GPT-5.6을 공개했어요. GPT-5.6은 Sol·Terra·Luna 세 모델로 나뉘어요. 예전 버전이랑 뭐가 다른지, ChatGPT 앱에서 바로 쓸 수 있는지만 짧게 정리해 볼게요.

GPT-5.6, 이름이 무슨 뜻인가요

GPT-5.6은 숫자가 세대를, Sol·Terra·Luna가 성능 등급을 가리키는 모델 패밀리예요. 공식 발표문은 이렇게 설명해요.

"The number identifies the generation, while Sol, Terra, and Luna are durable capability tiers that can advance on their own cadence." (OpenAI 공식 발표문, 2026.07.09 발표)

  • 숫자(5.6) — 모델 세대를 가리켜요.
  • Sol·Terra·Luna — 세대와 무관하게 이어지는 능력 등급이에요.

Sol·Terra·Luna 뭐가 다른가요

GPT-5.6의 세 모델은 성능·속도·가격이 각각 달라요.

  • Sol — 복잡한 추론·코딩에 맞는 플래그십이에요. 이런 작업엔 Sol부터 쓰라고 공식 문서가 안내해요.
  • Terra — 지능과 비용의 균형을 잡은 모델이에요.
  • Luna — 가장 빠르고 저렴한 등급이에요.

컨텍스트(한 번에 다룰 수 있는 글자 범위예요)는 세 모델 모두 1.05M로 같아요. 토큰은 AI가 텍스트를 처리하는 최소 단위예요. GPT-5.5·GPT-5.4도 1.05M라 여러 세대째 그대로예요. 대신 지식 컷오프(학습한 정보의 마지막 시점이에요)는 바뀌었어요. GPT-5.5는 2025-12-01, GPT-5.6은 2026-02-16이에요.

가격이 얼마나 바뀌었나요

GPT-5.6 Sol은 GPT-5.5와 가격이 같아요. 100만 토큰 기준으로 Sol은 입력 $5·출력 $30이에요.

Terra 가격은 GPT-5.4와 같아요. Luna는 입력 $1·출력 $6이고, GPT-5.4-mini(입력 $0.75·출력 $4.50)보다는 비싸지만 GPT-5.4보다는 저렴해요.

OpenAI는 가격은 그대로 두고 성능을 올렸다는 쪽을 강조해요. 지식노동 평가에서는 Terra가 GPT-5.5보다 낮은 비용으로 앞섰다고 밝혔어요. Luna는 GPT-5.5 최고 성능에 근접하고 비용은 절반 이하라고 밝혀요(자체 평가 기준).

ChatGPT 앱에서는 뭐가 달라지나요

ChatGPT 앱 기본 모델은 지금도 GPT-5.5 Instant예요. GPT-5.6이 나왔다고 앱 기본값이 바뀌지 않았어요.

공식 Help Center 문서를 보면, Sol이 유료 플랜 추론 옵션에 들어가요. 원문은 이렇게 적혀 있어요.

"GPT-5.6 Sol now powers the Medium, High, and Extra High reasoning options on eligible plans, while GPT-5.6 Sol Pro powers Pro." (OpenAI Help Center, 2026.07.23 확인)

표: ChatGPT 플랜별 GPT-5.6 추론 옵션 이용 가능 여부 (2026.07.23 기준)

표의 Pro 옵션 열은 GPT-5.6 Sol Pro가 구동해요.

순차 배포 중이라 아직 선택기에 안 보일 수 있어요. Free·Go 플랜은 표준 대화창 기준으로 GPT-5.6 추론 옵션이 열리지 않아요. Go의 Thinking은 GPT-5.6 Sol이 아니에요. 대신 Codex에서는 Free·Go도 GPT-5.6 Terra를 쓸 수 있어요.

새로 생긴 기능들

GPT-5.6은 공식 체인지로그 기준으로 개발자용 신기능이 여러 개 추가됐어요.

  • Programmatic Tool Calling — 모델이 직접 코드를 짜서 도구를 엮어 호출하는 방식이에요.
  • 명시적 프롬프트 캐시 컨트롤 — 반복 프롬프트의 캐시 여부를 개발자가 직접 정해요.
  • Persisted Reasoning — 이전 추론 과정을 이어서 쓸 수 있는 기능이에요.
  • Max 추론 강도(모델이 얼마나 깊게 생각할지의 단계예요) — 기존보다 한 단계 더 깊게 추론하는 옵션이에요. 이 위에 ultra 단계도 있는데, ChatGPT Work·Codex 쪽 설정이에요. API에서는 Responses API 멀티에이전트 베타로 비슷하게 구성해요.
  • Pro mode — 답 하나를 내놓기 전에 모델이 더 연산을 돌리는 API 실행 모드로, 추론 강도와는 별개예요.
  • 멀티에이전트 오케스트레이션(베타) — 여러 에이전트가 작업을 나눠 처리해요. Responses API(대화형 응답 API)에 베타로 열렸어요.

발표문 본문에는 53.6도 나오는데, 두 값의 측정 기준은 따로 안 나와 있어요. 벤더가 낸 비교라 참고만 하시면 돼요.

공식 모델 카탈로그 기준으로 gpt-5.6 별칭은 gpt-5.6-sol로 자동 연결돼요.

Q. ChatGPT 표준 대화창에서 Terra나 Luna를 직접 고를 수 있나요?
아니요. 표준 대화창엔 없고, ChatGPT Work(Plus 이상)·Codex·API에서만 골라 쓸 수 있어요.

Q. GPT-5.6 추론 한도를 다 쓰면 어떻게 되나요?
공식 문서는 추론 한도에 도달하면 ChatGPT가 GPT-5.4 Thinking mini로 이어갈 수 있다고 안내해요.
