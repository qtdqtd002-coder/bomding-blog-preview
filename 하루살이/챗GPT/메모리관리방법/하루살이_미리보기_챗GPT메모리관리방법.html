챗GPT 메모리 기능 켜고 끄고 관리하는 법

하루살이2026.08.08IT·AI 하우투

챗GPT 메모리는 설정에서 언제든 껐다 켤 수 있어요.

저장된 항목도 확인하고 고치거나 지울 수 있어요.

다만 메모리(Memory)라는 이름 아래 실제로는 두 가지 설정이 따로 움직여요.

하나는 직접 기억해달라고 한 저장된 메모리예요.

다른 하나는 지난 대화를 참고하는 채팅 기록 참조예요.

이 글에서는 메모리를 껐다 켜는 법부터 살펴볼게요.

저장된 항목을 확인·수정하는 법과 임시 채팅으로 기록을 안 남기는 법도 순서대로 다룰게요.

챗GPT 메모리 기능을 만든 오픈AI(OpenAI)의 공식 로고예요.

챗GPT 메모리, 왜 두 갈래로 나뉘나요?

챗GPT 메모리는 저장된 메모리와 채팅 기록 참조, 이렇게 두 축으로 나뉘어요.

저장된 메모리의 공식 명칭은 Reference saved memories예요.

채팅 기록 참조의 공식 명칭은 Reference chat history예요.

저장된 메모리는 내가 직접 기억해달라고 명시한 내용이에요.

채팅 기록 참조는 지난 대화 전체 중 챗GPT가 도움이 될 만하다고 판단한 내용이에요.

저장된 메모리는 지울 때까지 그대로 유지돼요.

채팅 기록 참조가 가져오는 내용은 시간이 지나며 바뀔 수 있어요.

항목저장된 메모리채팅 기록 참조
공식 명칭Reference saved memoriesReference chat history
기억하는 대상직접 기억해달라고 한 내용지난 대화 전체 중 도움될 만한 내용
유지 방식지울 때까지 유지시간 지나며 바뀔 수 있음

둘 다 켜거나 하나만 켜거나 둘 다 끌 수 있고, 언제든 바꿀 수 있어요.

계정에 따라 이 둘이 개별 토글로 보일 수 있어요.

또는 하나로 통합된 메모리 요약(Memory summary) 화면으로 보일 수도 있어요.

메모리 전체를 껐다 켜는 법

메모리 전체는 설정에서 언제든 껐다 켤 수 있어요.

공식 경로는 Settings > Personalization > Memory예요.

  1. 오른쪽 위 프로필 아이콘을 눌러요.
  2. Settings로 들어가요.
  3. Personalization 메뉴를 선택해요.
  4. Memory 항목에서 토글을 켜거나 꺼요.
🧠Settings → Personalization → Memory
화면은 오른쪽 위 프로필 아이콘을 눌러 Settings로 들어가요. 그다음 Personalization 메뉴 안의 Memory 항목을 열면 돼요. 같은 경로를 OpenAI 공식 도움말에서도 안내하고 있어요.

챗GPT 메모리 설정은 이 경로로 들어가요.

이 부분에 대해 OpenAI 공식 도움말은 이렇게 적어요. (2026.08.08 기준)

"Turning saved memory off won't delete anything that's already been remembered."

즉 메모리를 꺼도 그동안 기억된 내용이 한 번에 사라지지는 않아요.

새로 기억을 쌓는 것만 멈춰요.

저장된 메모리, 확인하고 고치는 법

저장된 메모리는 메모리 요약 화면에서 확인하고 내용을 고칠 수 있어요.

공식 명칭은 Memory summary예요.

다만 메모리 요약이 챗GPT가 기억하는 모든 내용을 다 보여주지는 않아요.

특정 내용을 기억하는지 궁금하면 대화창에서 직접 물어보는 게 더 정확해요.

고치는 방법은 두 가지예요.

  • 메모리 요약 아래 텍스트 박스에 바꾸고 싶은 내용을 입력해요.
  • 메모리 요약 안의 문구를 드래그해서 그 부분만 고쳐요.

특정 한 가지만 콕 집어 지우고 싶다면, 챗GPT에게 직접 "이거 잊어줘"처럼 말하는 방법이 공식적으로 안내돼요.

메모리 요약 화면 자체에 항목 하나씩 지우는 버튼이 있다고는 공식 도움말에 나와 있지 않아요.

화면에서 확인되는 삭제 버튼은 점 3개 메뉴의 "Delete and turn off memory"예요.

이 버튼을 누르면 화면에 보이는 메모리가 한꺼번에 지워지고 메모리 기능도 함께 꺼져요.

단, 지금까지 나눈 대화 자체는 지워지지 않아요.

채팅 기록 참조는 따로 꺼야 해요

채팅 기록 참조는 저장된 메모리를 꺼도 같이 꺼지지 않고, 따로 꺼야 해요.

공식 명칭은 Reference chat history예요.

프로필 아이콘을 누르고 Settings, Personalization 순서로 들어가요.

거기서 언제든 켜고 끌 수 있어요.

저장된 메모리와 채팅 기록 참조는 서로 독립된 스위치예요.

하나를 꺼도 다른 하나는 그대로 남아 있어요.

완전히 삭제하려면 어디까지 지워야 하나요?

완전히 삭제하려면 메모리 요약 한 곳만 지워서는 안 되고, 관련된 곳을 전부 지워야 해요.

OpenAI 공식 도움말은 삭제 대상을 이렇게 안내해요.

  • 그 내용이 나온 지난 대화
  • 보관된(archived) 대화
  • 업로드한 파일
  • 메모리 요약 화면의 해당 항목
  • 그 정보가 담겨 있을 수 있는, 연결된 앱의 연동 해제

즉 메모리 요약에서 하나만 지운다고 챗GPT가 그 사실을 완전히 잊는 건 아니에요.

참고로 지운 저장된 메모리 기록은 최대 30일까지 남을 수 있어요.

안전·오류 확인 목적이라고 공식 도움말에 적혀 있어요.

이번 대화만 기억 안 하게 하려면 — 임시 채팅

이번 대화만 기억에 남기고 싶지 않으면 임시 채팅을 쓰면 돼요.

공식 명칭은 Temporary Chat이에요.

OpenAI 공식 도움말은 임시 채팅을 이렇게 설명해요. (2026.08.08 기준)

"Temporary Chats do not use existing memories or create new memories."

이미 저장된 메모리나 채팅 기록 참조 내용을 끌어오지 않는다는 뜻이에요.

이 대화에서 새 메모리를 만들지도 않아요.

민감한 정보를 나누는 대화라면 메모리 자체를 끄는 방법이 있어요.

아니면 이렇게 임시 채팅을 쓰는 방법도 있어요.

회사·워크스페이스 계정이면 다를 수 있어요

회사나 워크스페이스 계정이면 관리자가 메모리 기능 자체를 꺼 두었을 수 있어요. 그러면 화면이 이 글과 다르게 보일 수 있어요. 자세한 내용은 OpenAI 비즈니스 버전 메모리 FAQ에서 확인할 수 있어요.

자주 묻는 질문

Q. 메모리를 껐다가 다시 켜면 예전에 기억하던 내용이 그대로 돌아오나요?
A. 아니요, 자동으로 되살아나지 않아요. 챗GPT가 남아 있는 대화 기록에서 새로 메모리를 만들 수 있어요. 여기에는 오래된 대화도 포함될 수 있어요.

Q. 메모리 요약 화면에 아무것도 안 보여요, 왜 그런가요?
A. 새 계정이거나 메모리를 막 켰거나 대화 기록이 부족하면 그래요. Settings의 Memory Summary에서 Manage로 들어가요. 거기서 점 3개 메뉴의 Refresh를 눌러볼 수 있어요.

Q. 메모리랑 커스텀 지시(Custom Instructions)는 뭐가 다른가요?
A. 커스텀 지시는 내가 직접 명시적으로 알려주는 지침이에요. 메모리는 대화 중 자연스럽게 나온 내용을 챗GPT가 스스로 기억하는 거예요.

채팅 기록 참조는 저장된 메모리를 꺼도 같이 꺼지지 않고, 따로 꺼야 해요.

공식 명칭은 Reference chat history예요.

프로필 아이콘을 누르고 Settings, Personalization 순서로 들어가요.

거기서 언제든 켜고 끌 수 있어요.

저장된 메모리와 채팅 기록 참조는 서로 독립된 스위치예요.

하나를 꺼도 다른 하나는 그대로 남아 있어요.

 

 

완전히 삭제하려면 어디까지 지워야 하나요?

완전히 삭제하려면 메모리 요약 한 곳만 지워서는 안 되고, 관련된 곳을 전부 지워야 해요.

OpenAI 공식 도움말은 삭제 대상을 이렇게 안내해요.

 

  • 그 내용이 나온 지난 대화
  • 보관된(archived) 대화
  • 업로드한 파일
  • 메모리 요약 화면의 해당 항목
  • 그 정보가 담겨 있을 수 있는, 연결된 앱의 연동 해제

 

즉 메모리 요약에서 하나만 지운다고 챗GPT가 그 사실을 완전히 잊는 건 아니에요.

참고로 지운 저장된 메모리 기록은 최대 30일까지 남을 수 있어요.

안전·오류 확인 목적이라고 공식 도움말에 적혀 있어요.

 

 

이번 대화만 기억 안 하게 하려면 — 임시 채팅

이번 대화만 기억에 남기고 싶지 않으면 임시 채팅을 쓰면 돼요.

공식 명칭은 Temporary Chat이에요.

OpenAI 공식 도움말은 임시 채팅을 이렇게 설명해요. (2026.08.08 기준)

"Temporary Chats do not use existing memories or create new memories."

이미 저장된 메모리나 채팅 기록 참조 내용을 끌어오지 않는다는 뜻이에요.

이 대화에서 새 메모리를 만들지도 않아요.

민감한 정보를 나누는 대화라면 메모리 자체를 끄는 방법이 있어요.

아니면 이렇게 임시 채팅을 쓰는 방법도 있어요.

 

 

회사·워크스페이스 계정이면 다를 수 있어요

회사나 워크스페이스 계정이면 관리자가 메모리 기능 자체를 꺼 두었을 수 있어요. 그러면 화면이 이 글과 다르게 보일 수 있어요. 자세한 내용은 OpenAI 비즈니스 버전 메모리 FAQ에서 확인할 수 있어요.

 

 

자주 묻는 질문

Q. 메모리를 껐다가 다시 켜면 예전에 기억하던 내용이 그대로 돌아오나요?
A. 아니요, 자동으로 되살아나지 않아요. 챗GPT가 남아 있는 대화 기록에서 새로 메모리를 만들 수 있어요. 여기에는 오래된 대화도 포함될 수 있어요.

Q. 메모리 요약 화면에 아무것도 안 보여요, 왜 그런가요?
A. 새 계정이거나 메모리를 막 켰거나 대화 기록이 부족하면 그래요. Settings의 Memory Summary에서 Manage로 들어가요. 거기서 점 3개 메뉴의 Refresh를 눌러볼 수 있어요.

Q. 메모리랑 커스텀 지시(Custom Instructions)는 뭐가 다른가요?
A. 커스텀 지시는 내가 직접 명시적으로 알려주는 지침이에요. 메모리는 대화 중 자연스럽게 나온 내용을 챗GPT가 스스로 기억하는 거예요.
