챗GPT 캔버스 사라진 이유와 대체 사용법

하루살이2026.08.08IT·AI 하우투

챗GPT 캔버스가 안 보이는 이유와, 지금 글쓰기·코딩을 어디서 하면 되는지. 사실 이 두 질문은 한 사건에서 나왔어요.

2026년 5월 28일 GPT-5.5 업데이트로 캔버스가 빠졌어요. 그 자리는 라이팅 블록과 코드 블록이 대신하고 있어요.

혹시 모델을 다른 걸로 바꾸면 캔버스가 돌아온다는 이야기를 들으셨을 수 있어요. 2026년 8월 8일 기준으로는 완전히 막힌 건 아니지만, 곧 끝나는 임시 통로예요.

캔버스가 정말 없어진 게 맞는지부터 짚었어요. 라이팅 블록·코드 블록 쓰는 법, 예전 캔버스 문서 챙기는 법도 순서대로 담았어요.

챗GPT 캔버스, 정말 없어졌나요?

네, 2026년 5월 28일 업데이트로 캔버스가 실제로 빠졌어요.

빠진 모델은 GPT-5.5 Instant와 GPT-5.5 Thinking이에요. 공식 영어 이름은 Canvas예요.

캔버스를 없애고 라이팅 블록·코드 블록을 넣은 오픈AI(OpenAI)의 공식 로고예요.

이미지 출처: openai.com 공식 로고 이미지

공식 릴리스 노트에는 이런 문장이 그대로 적혀 있어요.

"canvas will no longer be available in GPT-5.5 Instant or GPT-5.5 Thinking"

우리말로 옮기면 이런 뜻이에요. 캔버스는 이제 GPT-5.5 두 모델에서 쓸 수 없다는 말이에요. (OpenAI 공식 릴리스 노트, 2026.05.28 항목 기준)

  • 캔버스는 2026년 5월 28일부터 GPT-5.5에서 빠졌어요.
  • 글쓰기·코딩 기능은 채팅 응답 안의 라이팅 블록·코드 블록으로 옮겨졌어요.
  • 유료 사용자는 레거시 모델을 통해 한동안 캔버스를 계속 쓸 수 있었어요.

이 마지막 항목 때문에 "모델을 바꾸면 되는 거 아니냐"는 말이 나왔어요. 그런데 그 레거시 통로도 이제 거의 다 닫혀가고 있어요.

모델을 바꾸면 캔버스가 다시 뜨나요?

정확히는, "전혀 안 된다"가 아니라 "거의 다 끝나가는 임시 통로만 남았다"가 맞아요.

모델캔버스 지원 종료(모델 은퇴일 기준)
GPT-4.52026.06.27(30일 유예 후 종료)
OpenAI o32026.08.26(90일 유예 후 종료 예정)

공식 릴리스 노트에는 두 모델의 은퇴 예고일이 나와 있어요.

GPT-4.5는 2026년 6월 27일에 이미 은퇴해서, 이 경로는 완전히 끝났어요.

OpenAI o3는 2026년 8월 26일 은퇴 예정이에요. 오늘(2026년 8월 8일) 기준으로는 아직 지나지 않았어요.

공식 릴리스 노트 원문에는 이런 문장이 있어요.

"Paid users can continue using canvas for a limited time through legacy models until those models are sunset."

우리말로 옮기면 이런 뜻이에요. 유료 사용자는 레거시 모델이 은퇴하기 전까지 한동안 캔버스를 계속 쓸 수 있다는 말이에요. (OpenAI 공식 릴리스 노트, 2026.05.28 항목 기준)

그러니까 지금 OpenAI o3로 바꾸면 캔버스가 뜰 수도 있어요. 다만 이 통로도 2026년 8월 26일이면 완전히 닫혀요. 얼마 남지 않은 임시 통로일 뿐이에요.

그래서 "다른 모델로 바꾸면 캔버스가 된다"는 말은 반은 맞고 반은 틀려요. 곧 사라질 통로를 붙잡느니, 라이팅 블록과 코드 블록에 지금 익숙해지는 게 나아요.

라이팅 블록은 어떻게 쓰나요?

라이팅 블록은 채팅 응답 안에서 바로 고쳐 쓸 수 있는 초안 영역이에요.

영어로는 writing block이라고 불러요.

챗GPT가 나중에 고치거나 다시 쓸 만한 글을 만들면 자동으로 라이팅 블록에 담아줘요. 다음처럼 직접 요청해서 만들 수도 있어요.

  • "팀장님께 보낼 답장 이메일 초안 써줘"
  • "팀에 공유할 짧은 업무 공지 써줘"
  • "이 메모를 한 장짜리 문서로 정리해줘"
📝채팅 응답 안에 바로 뜨는 라이팅 블록
라이팅 블록은 캔버스처럼 옆에 새 창이 뜨지 않아요. 챗GPT 응답 메시지 안에 편집 가능한 영역으로 바로 나타나요. 자세한 화면은 OpenAI 공식 도움말에서 확인할 수 있어요.

라이팅 블록은 이런 방식으로 채팅 안에 나타나요.

만들어진 블록에서는 이런 것들을 할 수 있어요.

  • 블록을 선택해서 텍스트를 직접 고칠 수 있어요.
  • 텍스트를 그대로 복사할 수 있어요.
  • 선택한 부분이나 전체 초안을 다시 써 달라고 챗GPT에 요청할 수 있어요.
  • 블록을 전체 화면으로 열어서 편집할 수 있어요.
  • AI가 고친 내용을 실행 취소하거나 다시 실행할 수 있어요.
  • 지원되는 이메일 초안은 챗GPT에서 곧바로 보내거나 이메일 앱으로 열 수 있어요.

굵게·기울임, 제목, 링크, 글머리·번호 목록, 체크리스트 같은 서식도 그대로 지원돼요.

코드 블록으로는 뭘 할 수 있나요?

코드 블록은 코드를 채팅 응답과 분리해서 보여주는 영역이에요.

캔버스처럼 별도 창을 열지 않아도 되고, 영어로는 code block이라고 불러요.

지원되는 코드 블록에서는 이런 조작이 가능해요.

  • 코드를 복사할 수 있어요.
  • 파이썬·자바스크립트·HTML 같은 언어 이름이 라벨로 표시돼요.
  • 코드를 직접 고치거나, 챗GPT에 고쳐 달라고 요청할 수 있어요.
  • 코드 블록을 전체 화면으로 열 수 있어요.
  • 지원되는 파이썬 코드는 그 자리에서 실행하고 콘솔 결과까지 볼 수 있어요.
  • 지원되는 코드 블록은 읽기 전용 링크로 공유할 수 있어요.

미리보기가 지원되는 형식은 이렇게 다양해요.

  • HTML 페이지
  • React 컴포넌트
  • SVG 이미지
  • Mermaid 다이어그램
  • Vega·Vega-Lite 차트

코드와 결과 화면은 바로 전환해서 볼 수 있어요.

수정한 내용은 잠깐의 지연 후 자동으로 저장돼요. 다음 질문을 할 때 챗GPT가 최신 버전을 참고해요.

예전 캔버스 문서, 지금 어떻게 챙기나요?

예전 캔버스 문서는 챗GPT 설정의 전체 데이터 내보내기로 챙길 수 있어요.

낱개로 다시 여는 기능이 아니라, 대화 기록 전체를 내려받는 방식이에요.

📦설정 → 데이터 관리 → 데이터 내보내기
프로필 메뉴 → 설정 → 데이터 관리 → 데이터 내보내기에서 내보내기를 눌러요. 확인 화면에서 내보내기 확인을 다시 누르면 요청이 접수돼요. 자세한 절차는 OpenAI 공식 도움말에 나와 있어요.

전체 대화 기록 내보내기는 이 순서로 진행돼요.

  1. 프로필 메뉴를 열어요.
  2. 설정을 선택해요.
  3. 데이터 관리를 선택해요.
  4. 데이터 내보내기 항목에서 내보내기를 눌러요.
  5. 확인 화면에서 내보내기 확인을 눌러요.

요청이 접수되면 이메일이나 문자로 안내가 오는데, 최대 7일까지 걸릴 수 있어요.

안내 메시지에서 데이터 내보내기 다운로드를 누르면 돼요. 이 다운로드 링크는 받은 지 24시간이 지나면 만료돼요.

내려받은 ZIP 파일 안에는 대화 기록을 비롯한 계정 관련 데이터가 들어 있어요.

예전에 캔버스에서 작업했던 글이나 코드도 그 대화 안에서 확인할 수 있어요.

자주 묻는 질문

Q. 라이팅 블록·코드 블록은 어느 기기에서나 똑같이 다 되나요?
A. 아니요. 공식 도움말은 기기·요금제·설정에 따라 사용 가능한 동작이 다르다고 안내해요. 같은 대화에서도 매번 똑같은 기능이 다 뜨는 건 아니에요.

Q. 임시 채팅에서 만든 라이팅 블록도 나중에 다시 볼 수 있나요?
A. 아니요, 공식 도움말에는 임시 채팅 수정 내용이 대화 종료 후 사라질 수 있다고 나와요.

그러니까 지금 OpenAI o3로 바꾸면 캔버스가 뜰 수도 있어요. 다만 이 통로도 2026년 8월 26일이면 완전히 닫혀요. 얼마 남지 않은 임시 통로일 뿐이에요.

 

그래서 "다른 모델로 바꾸면 캔버스가 된다"는 말은 반은 맞고 반은 틀려요. 곧 사라질 통로를 붙잡느니, 라이팅 블록과 코드 블록에 지금 익숙해지는 게 나아요.

 

 

라이팅 블록은 어떻게 쓰나요?

라이팅 블록은 채팅 응답 안에서 바로 고쳐 쓸 수 있는 초안 영역이에요.

영어로는 writing block이라고 불러요.

챗GPT가 나중에 고치거나 다시 쓸 만한 글을 만들면 자동으로 라이팅 블록에 담아줘요. 다음처럼 직접 요청해서 만들 수도 있어요.

 

  • "팀장님께 보낼 답장 이메일 초안 써줘"
  • "팀에 공유할 짧은 업무 공지 써줘"
  • "이 메모를 한 장짜리 문서로 정리해줘"

 

라이팅 블록은 캔버스처럼 옆에 새 창이 뜨지 않아요. 챗GPT 응답 메시지 안에 편집 가능한 영역으로 바로 나타나요.

 

만들어진 블록에서는 이런 것들을 할 수 있어요.

  • 블록을 선택해서 텍스트를 직접 고칠 수 있어요.
  • 텍스트를 그대로 복사할 수 있어요.
  • 선택한 부분이나 전체 초안을 다시 써 달라고 챗GPT에 요청할 수 있어요.
  • 블록을 전체 화면으로 열어서 편집할 수 있어요.
  • AI가 고친 내용을 실행 취소하거나 다시 실행할 수 있어요.
  • 지원되는 이메일 초안은 챗GPT에서 곧바로 보내거나 이메일 앱으로 열 수 있어요.

 

굵게·기울임, 제목, 링크, 글머리·번호 목록, 체크리스트 같은 서식도 그대로 지원돼요.

 

 

코드 블록으로는 뭘 할 수 있나요?

코드 블록은 코드를 채팅 응답과 분리해서 보여주는 영역이에요.

캔버스처럼 별도 창을 열지 않아도 되고, 영어로는 code block이라고 불러요.

지원되는 코드 블록에서는 이런 조작이 가능해요.

 

  • 코드를 복사할 수 있어요.
  • 파이썬·자바스크립트·HTML 같은 언어 이름이 라벨로 표시돼요.
  • 코드를 직접 고치거나, 챗GPT에 고쳐 달라고 요청할 수 있어요.
  • 코드 블록을 전체 화면으로 열 수 있어요.
  • 지원되는 파이썬 코드는 그 자리에서 실행하고 콘솔 결과까지 볼 수 있어요.
  • 지원되는 코드 블록은 읽기 전용 링크로 공유할 수 있어요.

 

미리보기가 지원되는 형식은 이렇게 다양해요.

  • HTML 페이지
  • React 컴포넌트
  • SVG 이미지
  • Mermaid 다이어그램
  • Vega·Vega-Lite 차트

코드와 결과 화면은 바로 전환해서 볼 수 있어요.

수정한 내용은 잠깐의 지연 후 자동으로 저장돼요. 다음 질문을 할 때 챗GPT가 최신 버전을 참고해요.

 

 

예전 캔버스 문서, 지금 어떻게 챙기나요?

예전 캔버스 문서는 챗GPT 설정의 전체 데이터 내보내기로 챙길 수 있어요.

낱개로 다시 여는 기능이 아니라, 대화 기록 전체를 내려받는 방식이에요.

 

프로필 메뉴 → 설정 → 데이터 관리 → 데이터 내보내기에서 내보내기를 눌러요. 확인 화면에서 내보내기 확인을 다시 누르면 요청이 접수돼요.

 

  1. 프로필 메뉴를 열어요.
  2. 설정을 선택해요.
  3. 데이터 관리를 선택해요.
  4. 데이터 내보내기 항목에서 내보내기를 눌러요.
  5. 확인 화면에서 내보내기 확인을 눌러요.

 

요청이 접수되면 이메일이나 문자로 안내가 오는데, 최대 7일까지 걸릴 수 있어요.

안내 메시지에서 데이터 내보내기 다운로드를 누르면 돼요. 이 다운로드 링크는 받은 지 24시간이 지나면 만료돼요.

내려받은 ZIP 파일 안에는 대화 기록을 비롯한 계정 관련 데이터가 들어 있어요.

예전에 캔버스에서 작업했던 글이나 코드도 그 대화 안에서 확인할 수 있어요.

 

 

자주 묻는 질문

Q. 라이팅 블록·코드 블록은 어느 기기에서나 똑같이 다 되나요?
A. 아니요. 공식 도움말은 기기·요금제·설정에 따라 사용 가능한 동작이 다르다고 안내해요. 같은 대화에서도 매번 똑같은 기능이 다 뜨는 건 아니에요.

Q. 임시 채팅에서 만든 라이팅 블록도 나중에 다시 볼 수 있나요?
A. 아니요, 공식 도움말에는 임시 채팅 수정 내용이 대화 종료 후 사라질 수 있다고 나와요.
