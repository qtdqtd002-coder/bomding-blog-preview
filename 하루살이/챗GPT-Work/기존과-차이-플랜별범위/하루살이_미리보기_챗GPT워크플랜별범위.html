챗GPT 워크(ChatGPT Work)란 — 챗GPT·코덱스와 다른 점, 플랜별 이용 범위

하루살이2026.07.24· IT

OpenAI가 2026년 7월 9일 ChatGPT Work를 새로 선보였어요. ChatGPT Work는 기존 채팅 모드인 Chat, 개발자용 Codex와 나란히 있는 새로운 에이전트 모드예요. GPT-5.6이 이 모드를 구동하고, 여러 앱과 파일에 흩어진 맥락을 모아 문서·스프레드시트·프레젠테이션 같은 완성된 결과물을 만들어 줘요.

GPT-5.6의 세 성능 등급(Sol·Terra·Luna)은 이전 글에서 짚었어요. 이 글은 ChatGPT Work 자체와 데스크톱 앱 변화, 플랜별 이용 범위에 집중해 볼게요.

ChatGPT·Codex와 갈리는 지점은 얼마나 폭넓은 작업을 얼마나 오래 스스로 맡기느냐예요.

ChatGPT Work가 정확히 뭔가요

ChatGPT Work는 한 번의 대화형 답변이 아니라, 여러 단계로 나뉜 프로젝트를 끝까지 진행해 완성된 산출물을 내놓는 모드예요. 일반 Chat은 질문 하나에 답 하나를 주는 방식이에요. ChatGPT Work는 작업을 여러 단계로 쪼개고, 필요하면 몇 시간이고 계속 진행해요.

그 결과물도 답변 텍스트가 아니라 완성본이에요. 문서·스프레드시트·슬라이드·프레젠테이션·보고서, 간단한 웹앱까지 만들어 내요.

Codex와는 역할이 갈려요. Codex는 코드 작성·디버깅 같은 개발 작업 전용 모드예요. ChatGPT Work는 개발 업무에 한정되지 않고, 사무·기획·분석처럼 더 폭넓은 업무를 맡아요.

연동 범위도 넓어요. ChatGPT Work는 아래 도구들에 연결할 수 있어요.

  • 슬랙(Slack)·마이크로소프트 팀즈(Microsoft Teams)
  • 구글 드라이브(Google Drive)·셰어포인트(SharePoint)
  • 이메일·캘린더
  • CRM(고객관계관리 도구)·프로젝트 관리 도구

데스크톱 앱에서 챗·워크·코덱스가 어떻게 합쳐졌나요

새로 통합된 챗GPT 데스크톱 앱은 Chat·ChatGPT Work·Codex를 하나의 창 안에 탭으로 묶었어요. macOS·윈도우용으로 전 세계에 동시 배포됐어요.

기존 Codex 앱을 쓰던 사용자는 평소처럼 업데이트만 하면 이 통합 앱으로 넘어가요. 프로젝트·설정·작업 이력은 그대로 유지되고요. 새 앱 안에서 Codex는 Chat·Work 옆의 독립된 코딩 전용 탭으로 남아요.

이름이 바뀐 건 통합 앱이 아니라, 예전부터 쓰던 챗 전용 데스크톱 앱이에요. OpenAI 공식 발표는 이렇게 밝혀요.

"The existing version of the ChatGPT desktop app will be renamed ChatGPT Classic." (OpenAI 공식 발표, 2026.07.09)

예전 챗 전용 앱이 챗GPT 클래식(ChatGPT Classic)이라는 이름으로 남는다는 뜻이에요. 새 통합 앱으로 옮기고 싶지 않은 사용자를 위한 선택지고, 모델 업데이트·버그 수정·보안 패치·기존 Enterprise 기능 지원은 챗GPT 클래식에서도 계속돼요.

플랜별로 접근 범위가 어떻게 다른가요

ChatGPT Work의 웹·모바일 이용 시작 시점과, 데스크톱 앱에서 탭 자체가 보이는 범위는 플랜마다 달라요. 2026년 7월 9일 기준으로 웹·모바일은 Pro·Enterprise·Edu 플랜부터 먼저 열렸고, Plus·Business는 며칠에 걸쳐 순차로 확대됐어요.

표: 플랜별 ChatGPT Work 웹·모바일 오픈 시점과 데스크톱 앱 탭 노출 범위 (OpenAI 공식 발표 기준, 2026.07.09 발표 당시 안내 · 데스크톱 앱 탭 노출은 접속 가능 여부일 뿐 실사용량 제한은 별개)

ChatGPT Work는 별도 신규 구독 등급이 아니에요. 기존 Plus·Pro·Business·Enterprise 플랜에 추가 요금 없이 포함돼요. 다만 Work 사용량은 Codex와 같은 풀에서 차감되고, Business·Enterprise·Edu 플랜은 한도를 넘기면 크레딧을 추가로 구매해야 할 수 있어요.

데스크톱 앱은 Free 플랜을 포함한 모든 플랜에서 Chat·Work·Codex 탭 자체는 열려 있어요. 정확한 무료 사용량 수치는 공식적으로 공개돼 있지 않지만, ChatGPT Work도 Codex와 같은 사용량 구조를 따르기 때문에 무거운 작업일수록 더 많은 사용량을 쓴다는 점은 공식적으로 안내돼 있어요. 그래서 실제로 쓸 수 있는 양은 플랜마다 달라요.

예약작업으로 슬랙·팀즈 메시지를 자동 정리해 주나요

네. ChatGPT Work의 예약작업(Scheduled Tasks)은 사용자가 자리를 비운 사이에도 계속 작업을 진행해요.

슬랙·팀즈에 새로 들어온 메시지를 감지하면, 그 내용을 최신 문서나 슬라이드로 자동 정리해서 팀원들과 공유해요. 한 번 설정해 두면 이 정리 작업이 계속 순환돼요.

복잡한 프로젝트도 이 방식으로 여러 단계에 걸쳐 몇 시간이고 이어서 진행할 수 있어요. 사람이 매번 다시 지시하지 않아도 되는 셈이에요.
