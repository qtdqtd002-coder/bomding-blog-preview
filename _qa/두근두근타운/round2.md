## 특기 점검(사용자 지정)
1. #copy 생존본 마커/검증평문 누출 = 🟢 0건
   (🔍·.chk·.gap·✍️·[확인·"게임 내 확인"·나무위키·교차확인·커뮤니티·sidenote·rev-hl·pvbar·.ss·.shoot 전부 0)
   → lessons/qa 2026-07-06[봄딩] '#copy 마커 누출' 재발 없음. 06-27 외주첨부 격리 무관 글.
2. ㆍ(U+318D) 혼입 = 🟢 0건(전체 파일). 점=마침표(.)만 사용.
3. 교차오염(겜더쿠/영도/연봄) = 🟢 없음
   - "오늘 내용 정리"/"한 줄 요약"/"한 줄 정리"/"주인장"/" :)" 0
   - 번호섹션 소제목(1./2./3.) 0 → K장대로 구어체 질문형 헤더("뭐가 새로 나와요?" 등)
   - 마무리 '댓글' 클로징 0 (2026-06-13 영도 댓글클로징 오염 없음)
   - 마무리 헤더 "두근두근타운 고래 탐사 시즌 정리" = 주제명 박은 봄딩식 「○○ 정리」(영도 라벨 아님) 🟢
4. 어미 다양화 = 🟡 결함(반복)
   - #copy 종결어미 실측: ~것 같아요 10 / ~데요 7 / ~까요 4 / ~더라고요 3 / ~거든요 3 / ~잖아요 2
     ~네요 0 · ~답니다 0 · ~죠 0
   - 미리보기 본문(.post)도 동일 분포(문면 일치 확인): 네요0·답니다0·죠0, 것같아요10
   - "~것 같아요"가 문단 종결마다 10회 도배(도입·코스튬·도감·순서·정리 전 섹션 말미).
     실측 위치: "잡은 것 같아요/확인해야 할 것 같아요/훑어보시는 게 좋을 것 같아요/아까운 라인업일 것 같아요/
     준비를 해두시는 것도 좋을 것 같아요/놓치는 게 없을 것 같아요/참고만 해두시면 될 것 같아요/
     효율적일 것 같아요/재미를 살리는 방법일 것 같아요/채울 수 있을 것 같아요" (10)
   - 위반 규칙: style-guide R-2 '어미 다양화 ~네요(매우 빈번)·답니다·죠 고루' + feedback-log 2026-05-31
     "~데요 일변도 금지, 검수2가 ~네요 0건이면 지적" + 완화추측(것같아요) 남발 자제.
     → lessons/qa 2026-07-06[봄딩] '어미 ~네요 0건이면 동반 🟡'의 재발.

## 교정 권고(정보 유지, 문체만 순정으로)
완화추측 "~것 같아요" 10회 중 6~7회를 봄딩 순정 어미로 분산(정보/뉘앙스 손실 없음):
- "…방향으로 잡은 것 같아요" → "…방향으로 잡았더라고요"
- "…확인해야 할 것 같아요" → "…직접 확인해봐야겠더라고요" 또는 "…확인하는 게 정확하겠죠"
- "…훑어보시는 게 좋을 것 같아요" → "…한 번 훑어보시는 걸 추천드려요"
- "…아까운 라인업일 것 같아요" → "…그냥 넘기긴 아까운 라인업이네요"
- "…마음의 준비를 해두시는 것도 좋을 것 같아요" → "…미리 마음의 준비를 해두시면 좋답니다"
- "…놓치는 게 없을 것 같아요" → "…꾸준히 봐야 놓치는 게 없죠"
- "…채울 수 있을 것 같아요" → "…어렵지 않게 채울 수 있을 거예요" (마무리 변주)
※ 미리보기 본문(.post)과 #copy 두 곳을 동일하게 교정(문면 일치 유지). ~네요 최소 2~3회, ~답니다/~죠 각 1회 이상 편입.
