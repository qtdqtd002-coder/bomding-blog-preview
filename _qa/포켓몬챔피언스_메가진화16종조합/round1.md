## 발견

### 🔴 1. img/ 폴더 전체가 git 미추적(untracked) — 라이브 이미지 깨짐 위험
`git status --short` 결과 "겜더쿠/포켓몬 챔피언스/메가진화 16종 조합/" 전체가 `??`(untracked). 티스토리 본문 img src는 GitHub Pages 절대 URL(`https://qtdqtd002-coder.github.io/bomding-blog-preview/.../img/*.png`)을 가리키는데, 실제 리포에 push되지 않으면 이 URL은 404가 된다. 기존 교훈(broken-live-images-untracked-img.md)의 1순위 의심 패턴과 정확히 일치.
- 교정: 발행 전 `git add "겜더쿠/포켓몬 챔피언스/메가진화 16종 조합/"`(경로 명시, -A 금지)로 img 3장+HTML 2개 commit·push 후 라이브 URL 200 확인.

### 🔴 2. "16종" 약속 대비 본문 실제 취급 종수 = 14종 (2종 완전 누락)
제목·리드·"이 글 한눈에"·본문 강조문·FAQ·한 줄 정리에서 "16종"이 총 16회 반복되지만, 실제 표+산문에서 다룬 메가는 14종(라이츄Y·찌르호크·칼라마네로·번치코·메타그로스·화염레오·거북손데스·입치트·곤율거니·드래캄·펜드라·저리더프·대짱이·대여르). 상단 작성자 확인 주석(PREMISE)이 검증한 16종 명단 중 **라이츄X**(Raichu X)와 **나무킹**(Sceptile)이 본문에 0회 등장 — 나무킹은 주석에만 이름이 나오고 발행 본문엔 전혀 없음.
- 영향: 게임 공략 목적상 "16종 전수 조합 가이드"를 표방했는데 1/8이 빠진 채 발행되면 정보 완전성 결함이자 제목-본문 불일치(SEO 신뢰도 문제). 검색 유입 독자가 "라이츄X는요?" "나무킹은 왜 없어요?" 이탈 요인.
- 교정: 두 가지 중 택1 — (a) 나무킹·라이츄X를 탱커·서포터 섹션 산문(현재 대짱이·대여르 다루는 문단)에 1~2문장씩 추가해 실제 16종 채우기, 또는 (b) 제목·본문의 "16종"을 실제 커버 종수(14종)로 정정하거나 "16종 중 핵심 14종" 식으로 스코프를 명시. 정보 누락보다는 (a) 보강을 권고(작성팀 환류).

### 🟡 3. 태그 불일치 — 주석 태그(7개) ≠ 본문/미리보기 표시 태그(6개)
파일 상단 `<!-- 태그: -->` 주석은 `포켓몬챔피언스,포켓몬챔피언스메가진화,레귤레이션MB,포켓몬랭크배틀,메가라이츄,메가메타그로스,포켓몬챔피언스공략` 7개(메가라이츄 포함)인데, 실제 본문 하단 태그 pill과 미리보기 `.tags` div는 `#포켓몬챔피언스 #포켓몬챔피언스메가진화 #레귤레이션MB #포켓몬랭크배틀 #메가메타그로스 #포켓몬챔피언스공략` 6개(메가라이츄 없음)로 서로 다르다. 티스토리 복사 버튼(tcopy)은 `pick(t,'태그')`로 주석 값을 "태그" 입력창에 채우는 구조라, 실제 게시 시 티스토리 태그 메타(검색용)=7개와 본문 노출 pill=6개가 어긋나게 된다.
- 교정: 주석 태그에서 `메가라이츄` 제거해 6개로 통일(또는 본문 pill에 `#메가라이츄` 추가해 7개로 통일). 어느 쪽이든 두 세트를 일치시켜야 함.
