# 금융왕 김복리 — 블로그 디자인 적용 세트

bokriking.tistory.com에 브랜드(딥그린 #0B7A4B + 골드 #C0892E)를 통일 적용하는 파일 모음입니다.
**아래 3가지(CSS · 프로필 · 파비콘)만 적용하면 끝**입니다.

---

## 📦 파일 목록
| 파일 | 용도 |
|---|---|
| `김복리_브랜드.css` | ★스킨 CSS (딥그린+골드 통일 · 연녹색 배경 · 알약 탭) |
| `김복리_프로필.jpg` | 프로필 이미지 (새 마스코트, 12KB — 100KB 이하) |
| `favicon.ico` | ★파비콘 (₩ 골드 코인, 16·32·48 포함 — 티스토리는 .ico만 허용) |
| `favicon-180.png` | (선택) 대표이미지용 큰 아이콘 |
| `배너_스킨HTML.txt` | ★메인 홈 배너(일러스트 배경형) — 스킨편집 HTML탭에 넣는 스크립트 |
| `_검증_미리보기.html` | 붙여넣기 전 로컬 미리보기 |

## 1) 스킨 CSS 적용  ★가장 중요
1. 티스토리 **[꾸미기 → 스킨편집]** → 우측 **[html/css 편집]**
2. **CSS 탭**으로 이동 → **맨 아래로 스크롤**
3. `김복리_브랜드.css`의 **전체 내용을 복사해 CSS 맨 끝에 붙여넣기** (기존 CSS는 지우지 말고 그 아래에 추가)
4. **[적용]** 저장
5. **[스킨 옵션]** 에서 **목록 형태 = ‘썸네일형(가로 카드)’** 로 설정하면 시안처럼 가로 카드로 보입니다.

> 브랜드 CSS는 기존 스킨을 덮어쓰는 ‘오버라이드’ 방식이라, 레이아웃은 그대로 두고 색·폰트·카드·소제목만 브랜드로 바뀝니다. 문제 생기면 붙여넣은 부분만 지우면 원상복구됩니다.

## 1-2) 메인 홈 배너 (일러스트 배경형)  ★신규
배너는 CSS만으로는 안 되고, HTML에 스크립트 1개를 더 넣어야 합니다. (배경 이미지·색·버튼 디자인은 위 `김복리_브랜드.css`에 이미 내장돼 있습니다.)
1. 티스토리 **[꾸미기 → 스킨편집]** → **[html/css편집]** → **HTML 탭**
2. `배너_스킨HTML.txt` 안의 **`<script> … </script>` 블록을 복사**해 맨 아래 **`</body>` 바로 위**에 붙여넣기
3. **[적용]** 저장 → 홈(bokriking.tistory.com)을 새로고침하면 상단에 배너가 뜹니다
- 배너는 **홈에서만** 표시됩니다(글·카테고리·검색 화면엔 안 나옴).
- 버튼 4개(정부지원금·세금·저축·대출)는 **사이드바 카테고리 주소를 자동으로 찾아 연결**됩니다. 카테고리를 새로 만들면 자동으로 링크가 붙습니다.
- 배너가 안 뜨면: ①CSS가 최신본인지(배경 이미지가 CSS에 내장) ②HTML에 스크립트가 들어갔는지 확인.

## 2) 프로필 이미지
- **[관리 → 블로그]** → **블로그 정보 / 프로필 이미지**에 `김복리_프로필.jpg` 업로드 (12KB, 용량 제한 통과)

## 3) 파비콘 (★.ico 파일)
- **[관리 → 블로그]** 하단 **파비콘**에 `favicon.ico` 업로드 (티스토리는 .ico만 허용 — 그래서 .ico로 만들었습니다)
- (선택) **대표이미지**에는 `favicon-180.png`
- 파비콘 = 브라우저 탭에 뜨는 딥그린 ₩ 코인

- **붙여넣기 전**: `_검증_미리보기.html`을 브라우저로 열어 색·카드·소제목·박스가 브랜드로 잘 나오는지 확인 (※원본 스킨 이미지 아이콘 일부는 로컬에선 안 보일 수 있음 — 실제 티스토리에선 정상)
