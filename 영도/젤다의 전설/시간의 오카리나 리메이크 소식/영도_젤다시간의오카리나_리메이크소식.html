스위치 2 본체도 젤다의 전설 40주년 특별 디자인 닌텐도 스위치2라는 이름으로 나오는데요, 출시일이 리메이크보다 약 일주일 앞선 10월 29일이라는 점이 흥미롭더라고요. 본체 먼저 손에 넣고, 일주일 뒤 게임으로 달리는 구성이네요 ㅋㅋ

에디션 본체 구성도 꼼꼼하게 살펴봤는데요. 조이콘(L)/(R)이 링크·젤다 디자인의 초록·금색으로 나오고, 조이콘 그립·손목 스트랩 2개·AC 어댑터·USB-C 케이블·HDMI 케이블이 동봉됩니다. 단, 게임 소프트웨어는 포함되지 않아요. 리메이크는 11월 5일에 별도로 구매해야 하는 구성이라서, 이 점은 확인해 두시는 게 좋을 것 같아요. 프로 컨트롤러와 케이스도 동일한 디자인으로 별도 판매(2026년 10월 29일)된다고 하네요. 일본 기준 본체는 62,980엔, 프로 컨트롤러 12,980엔, 케이스 3,980엔이고 한국 가격은 아직 미공개 상태입니다. 🔍 공식 확인

  • 대시 기능 추가 — 원작에 없던 달리기 버튼이 생겼습니다. 이동이 훨씬 편해질 것 같아요.
  • 시간 흐름 방식 변경 — 원작에서는 특정 공간에 있어야 시간이 흘렀는데, 이번엔 어디에 있든 시간이 흐르도록 바뀐다고 합니다.

대시 버튼 하나만 봐도 체감이 확 달라질 것 같은데요. 원작 시절에는 느린 이동 속도가 은근히 답답했던 기억이 있어서, 이 변경은 꽤 반갑더라고요.

이번 다이렉트에서 아오누마 에이지 프로듀서는 "원작의 40주년 시점에 맞춰 현대적 해석과 기술로 재탄생시켰다"고 소개하며 네 가지 새 기능을 직접 선보였는데요. 유튜브에 영상이 올라와 있어서 직접 돌려봤는데요. 콧노래 오카리나 파트에서 아오누마 프로듀서가 실제로 태양의 노래를 흥얼거리자 게임 화면 안에서 밤이 낮으로 바뀌는 장면이 나오더라고요. 기능 설명이 아니라 눈앞에서 되는 걸 직접 보여주니까 '아, 이게 진짜 구현됐구나' 싶었습니다.

신기능 4가지를 정리하면 이렇습니다.

번호신기능내용
①360도 카메라 회전원작 고정 카메라의 한계를 넘어 자유롭게 시점 전환 가능
②버튼 조작 점프원작에 없던 점프를 버튼으로 추가, 이동·전투 폭이 넓어짐
③마이크 콧노래 오카리나마이크에 콧노래를 불어 오카리나를 연주하는 기능
④여정의 기록진행 상황을 확인할 수 있는 일지 기능

개인적으로 가장 눈길을 끈 건 ③ 마이크 콧노래 연주인데요. 원작에서 오카리나 연주가 핵심 퍼즐 메커니즘이었던 만큼, 실제로 노래를 불어 진행한다는 아이디어가 꽤 참신하더라고요(?). Switch 2의 마이크 기능을 제대로 활용하는 사례가 나왔다는 것도 흥미롭고요.

② 버튼 점프도 주목할 만합니다. 원작 시간의 오카리나는 점프가 달리기 중 자동으로 발동하는 방식이었거든요. 버튼 점프가 추가되면 전투와 탐색 자유도가 대폭 올라갈 텐데, 원작의 감각을 어떻게 살릴지 궁금하네요.

원작에서 달라진 점들 — 신기능 4가지 외

인벤 기사에서 추가로 확인한 변경 사항들도 있어서 같이 정리해 드릴게요. 4가지 신기능 외에도 꽤 손을 많이 댔더라고요.

  • 대시 기능 추가 — 원작에 없던 달리기 버튼이 생겼습니다. 이동이 훨씬 편해질 것 같아요.
  • 시간 흐름 방식 변경 — 원작에서는 특정 공간에 있어야 시간이 흘렀는데, 이번엔 어디에 있든 시간이 흐르도록 바뀐다고 합니다.
  • 고정 카메라 구간 해제 — 하이랄성 마을을 이제 자유롭게 탐색할 수 있게 됐습니다.
  • 날씨 시스템 — 코키리의 숲에 안개·연기 연출이 추가돼 분위기가 한층 강화된다고 하네요.

대시 버튼 하나만 봐도 체감이 확 달라질 것 같은데요. 원작 시절에는 느린 이동 속도가 은근히 답답했던 기억이 있어서, 이 변경은 꽤 반갑더라고요.
