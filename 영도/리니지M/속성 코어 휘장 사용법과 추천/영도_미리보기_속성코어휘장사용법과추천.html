리니지M 속성 코어 휘장 사용법, 이그니스 운디네 실프 클레이 4속성 뭐가 좋을까? 선택 기준 정리

영원한도시2026.10.05· 게임
※ 다른 공략은 댓글을 참고해 주세요.

속성 코어, 4종 중에 어느 걸 골라야 할지 막막하시죠. 먼저 솔직하게 말씀드리면, 제가 확인한 범위에서 공식 공지(인벤 전재본 기준)에도 유저 정보글에도 '이 속성이 정답'이라는 내용은 없었습니다. 그래서 이 글은 정답을 찍어 드리는 대신, 확인된 사용 방법과 코어 기능에서 읽히는 선택 기준(제 의견)을 나눠서 정리했어요.

기준은 2026년 6월 24일 PHOENIX 패치, 내용을 다시 확인한 날은 2026년 10월 5일입니다. 이후에 속성 코어가 개편됐는지는 확인하지 못했어요.

1. 속성 코어(휘장)란, 핵심은 속성 관통

속성 코어는 6월 24일 PHOENIX 업데이트에서 휘장 전용으로 들어온 '속성 제련'에 쓰는 재료이고, 불ㆍ물ㆍ바람ㆍ땅 4속성 중 하나의 제련 효과를 휘장에 붙여 줍니다.

핵심은 새로 생긴 스탯 '속성 관통'이에요. 공식 공지 기준으로 속성 관통 수치만큼 맞은 캐릭터의 같은 속성 저항이 깎이고, 관통이 저항을 넘으면 속성 대미지가 증폭됩니다. 상대 저항이 방어막이라면 관통은 그 막을 깎아 내는 송곳 같은 거죠. 반대로 관통이 저항에 못 미치면 증폭까지는 못 간다고 읽히는데, 이건 공식 문구에서 제가 풀어 본 해석이에요. 물ㆍ불ㆍ바람ㆍ땅 속성 관통은 스탯 정보창에서 확인할 수 있어요.

📷스샷 1: 스탯 정보창의 속성 관통 항목
📸 직접 촬영 권장 — 스탯 정보창에서 물ㆍ불ㆍ바람ㆍ땅 속성 관통 항목이 한 화면에 보이게 캡처. 패치 내용 확인: 리니지M 공식 업데이트 공지

스탯 정보창을 보시면 속성 관통 항목이 따로 잡혀 있습니다.

2. 속성 코어 획득처, 방어전 주화 40개

속성 코어는 요정 숲 방어전 시즌 상점에서 방어전 주화 40개로 '속성 코어(휘장) 선택 상자 (이벤트)'를 사서 4종 중 1종을 고르는 방식이 6월 24일 패치 기준으로 확인된 획득 경로입니다.

  • 요정 숲 방어전 시즌 상점: 방어전 주화 40개 → '선택 상자' → 4종 중 1종 선택(계정당 50회)
  • 방어전 주화는 요정 숲 방어전과 듀펠게넌 잔당 토벌의 보상으로 모아서 같은 시즌 상점에서 씁니다

시즌 상점 판매 기간은 2026년 6월 24일부터 7월 15일 정기점검 전까지였고, 이 상자에서 나오는 코어는 '(이벤트)'가 붙은 코어라 이 코어로 제련하면 기간제 효과가 부여됩니다. 10월 5일 현재 같은 상자를 아직 파는지는 확인하지 못했어요. 선택 상자는 말 그대로 하나만 고르는 거라, 뭘 받느냐가 곧 속성 선택이에요. 고르기 전에 아래 5번 항목의 기준을 한 번 보고 오세요.

📷스샷 2: 방어전 시즌 상점의 속성 코어 선택 상자
📸 직접 촬영 권장 — 시즌 상점 목록에서 '속성 코어(휘장) 선택 상자'와 방어전 주화 40개 가격이 같이 보이게 캡처.

상점 목록에서 선택 상자 가격(주화 40개)을 같이 잡아 두면 좋아요.

3. 사용 순서, 축복받은 휘장 먼저 그다음 제련

속성 제련은 축복받은 휘장을 먼저 만든 뒤에 하는 게 안전한데, 축복받은 휘장을 만들면 재료로 쓴 휘장의 속성 제련 효과가 전부 삭제되기 때문입니다.

  1. 같은 휘장 2개로 축복받은 휘장을 만든다(공식 공지 기준 +3 이상)
  2. 축복받은 휘장에 속성 제련을 한다
  3. 다시 제련하면 기존 옵션을 지우고 새 옵션으로 덮어쓴다
📷스샷 3: 축복받은 휘장 속성 제련 화면
📸 직접 촬영 권장 — 축복받은 휘장을 올려 둔 속성 제련 화면 전체. 제련 전 화면과 후 화면을 나란히 쓰면 흐름이 보입니다.

보시는 것처럼 축복받은 휘장을 먼저 만들고 나서 이 화면으로 오시면 됩니다.

축복받은 지휘관의 휘장은 +6부터 '레벨에 의한 스킬 성공 확률 1단계 상승'(+7은 2단계)이 붙고 +7부터 스턴 시간 감소(1초)가 더해집니다. 축복받은 사냥꾼의 휘장은 +6부터 확률 대미지 리덕션, +7부터 '발동: 미티어 스트라이크'가 붙으니 이쪽도 같이 보고 만드세요.

▶ 순서 한 줄 요약 선택 상자(주화 40개) → 코어 1종 선택 → 축복받은 휘장 제작 → 속성 제련 → 마음에 안 들면 재제련

제련 옵션은 인챈트 단계별 확률로 붙고, 종류는 이렇습니다.

  • 속성 치명타, 속성 치명타 저항
  • 속성 추가 대미지, 속성 대미지 리덕션
  • 속성 저항, 속성 관통 등

휘장 강화도에 따라 붙는 옵션 그룹도 갈립니다.

휘장 강화도붙는 옵션 그룹

+5 이상1ㆍ2그룹 확정
+7 이상1ㆍ2그룹 확정 + 3그룹 확률
📷스샷 4: 속성 제련 결과로 붙은 옵션
📸 직접 촬영 권장 — 제련을 마친 휘장의 옵션 목록이 전부 보이게 캡처(강화도가 같이 보이면 위 표와 대조하기 좋아요).

지금 보시는 화면처럼 강화도와 옵션 줄을 같이 담아 두세요.

4. 4속성 한눈에, 이그니스ㆍ운디네ㆍ실프ㆍ클레이

속성 코어는 이그니스(불), 운디네(물), 실프(바람), 클레이(땅) 4종이고, 공지에서 확인되는 차이는 제련 속성이 불ㆍ물ㆍ바람ㆍ땅으로 갈린다는 점입니다. 속성 관통은 제련 때 확률로 붙는 6종 옵션 중 하나라서, 코어를 쓴다고 그 속성 관통이 꼭 붙는 건 아니에요.

📷스샷 5: 코어 4종 툴팁 비교
📸 직접 촬영 권장 — 이그니스ㆍ운디네ㆍ실프ㆍ클레이 툴팁을 같은 배율로 한 장씩 찍어 2×2로 이어 붙이기.

코어 4종 툴팁을 같은 배율로 나란히 놓은 화면입니다.

이 4종은 요정 숲 방어전의 '정령의 가호'(파티장이 이그니스ㆍ운디네ㆍ실프ㆍ클레이 중 선택)와 이름이 같고, 방어전에서는 속성 상성이 PvE 이득과 PvP 우위에 관여한다고 해요. 다만 휘장 코어와 이 정령이 직접 이어진다는 규칙은 확인하지 못했습니다. 이름이 같다고 정령에 맞춰 고르면 된다고는 단정하기 어려워요.

5. 어느 속성이 추천? 정답은 없고 기준만 있다

제가 확인한 범위에서는 어느 속성이 제일 낫다는 정답이 공식 공지(인벤 전재본 기준)에도, 유저 정보글에도 없었습니다.

아래는 확인된 사실이 아니라 코어 기능에서 읽은 제 의견이고, 관통이 붙었을 때 기준입니다. 관통이 상대의 같은 속성 저항을 깎는 구조니까, 고르는 기준도 '누구를 상대하느냐'에서 나올 수밖에 없다고 봅니다.

내 상황제 의견
자주 가는 사냥터가 정해져 있다그 몬스터의 속성 저항부터 살펴보고, 저항이 낮은 속성 쪽 관통이 증폭 구간에 닿기 쉬울 것 같아요
PvP 상대가 정해져 있다상대 캐릭터의 속성 저항을 보고 같은 논리로 고르세요
아직 기준이 없다코어를 고르기 전에 상대할 곳부터 정하세요

코어는 한 번에 1종만 고르는 구조라, 관통이 붙더라도 고른 속성 하나에만 해당해요. 상대가 그 속성 저항을 두껍게 두르고 있으면 관통이 저항을 넘기 어려울 수 있으니, '무슨 속성이 강하냐'보다 '내 상대가 어느 속성에 허술하냐'를 먼저 묻는 게 맞아 보입니다.

참고로 예전 무기 속성 인챈트 기사에는 물>불>땅>바람>물 상성이 있었는데요, 이건 구형 무기 속성 기준이고 휘장 코어가 같은 상성이라고 확인된 바는 없습니다. 그대로 대입하진 마세요. 주인장이라면 코어 고르기 전에 자주 가는 사냥터 몬스터 이름부터 적어 볼 것 같네요 ㅋㅋ

6. 헷갈리기 쉬운 실수와 아직 모르는 것

  • 속성 제련을 먼저 하고 축복받은 휘장을 만들면 제련 효과가 전부 사라집니다
  • 다시 제련하면 기존 옵션이 덮어써지니, 마음에 드는 옵션이 붙었다면 재제련 전에 한 번 더 고민하세요
  • 3그룹 옵션은 +7 이상 휘장에서만 확률로 붙습니다
  • 속성 제련은 강화 UI에서 하고 속성 코어(휘장) 1개가 필요합니다(공식 공지 기준)
  • 코어 이름이 방어전 정령과 같다고 해서 정령 속성에 맞춰 고르는 건 근거가 없으니 조심하세요(직접 연동은 확인되지 않았어요)

아직 모르는 건 옵션별 수치와 확률, 그룹별 옵션 목록, 몬스터별 속성 저항, 4종의 속성 외 고유 효과, 지금도 시즌 상점에서 이 상자를 파는지예요. 공지와 정보글에 나와 있지 않아서 이 글에는 적지 않았고, 새로 나오면 추후 정리해서 알려드릴게요.

핵심만
순서는 축복받은 휘장 먼저, 속성 제련은 그다음이고, 4종 중에서는 상대할 대상의 저항 속성을 기준으로 고르는 게 제 의견입니다(관통이 붙었을 때 기준). 6월 24일 패치 기준이에요.

1. 속성 코어(휘장)란, 핵심은 속성 관통

속성 코어는 6월 24일 PHOENIX 업데이트에서 휘장 전용으로 들어온 '속성 제련'에 쓰는 재료이고, 불ㆍ물ㆍ바람ㆍ땅 4속성 중 하나의 제련 효과를 휘장에 붙여 줍니다.

핵심은 새로 생긴 스탯 '속성 관통'이에요. 공식 공지 기준으로 속성 관통 수치만큼 맞은 캐릭터의 같은 속성 저항이 깎이고, 관통이 저항을 넘으면 속성 대미지가 증폭됩니다. 상대 저항이 방어막이라면 관통은 그 막을 깎아 내는 송곳 같은 거죠. 반대로 관통이 저항에 못 미치면 증폭까지는 못 간다고 읽히는데, 이건 공식 문구에서 제가 풀어 본 해석이에요. 물ㆍ불ㆍ바람ㆍ땅 속성 관통은 스탯 정보창에서 확인할 수 있어요.

└ 캡션 추천: "스탯 정보창을 보시면 속성 관통 항목이 따로 잡혀 있습니다."

2. 속성 코어 획득처, 방어전 주화 40개

속성 코어는 요정 숲 방어전 시즌 상점에서 방어전 주화 40개로 '속성 코어(휘장) 선택 상자 (이벤트)'를 사서 4종 중 1종을 고르는 방식이 6월 24일 패치 기준으로 확인된 획득 경로입니다.

  • 요정 숲 방어전 시즌 상점: 방어전 주화 40개 → '선택 상자' → 4종 중 1종 선택(계정당 50회)
  • 방어전 주화는 요정 숲 방어전과 듀펠게넌 잔당 토벌의 보상으로 모아서 같은 시즌 상점에서 씁니다

시즌 상점 판매 기간은 2026년 6월 24일부터 7월 15일 정기점검 전까지였고, 이 상자에서 나오는 코어는 '(이벤트)'가 붙은 코어라 이 코어로 제련하면 기간제 효과가 부여됩니다. 10월 5일 현재 같은 상자를 아직 파는지는 확인하지 못했어요. 선택 상자는 말 그대로 하나만 고르는 거라, 뭘 받느냐가 곧 속성 선택이에요. 고르기 전에 아래 5번 항목의 기준을 한 번 보고 오세요.

📷 〔사진 자리 2〕 방어전 시즌 상점의 속성 코어 선택 상자 — 네이버에서 직접 업로드

└ 캡션 추천: "상점 목록에서 선택 상자 가격(주화 40개)을 같이 잡아 두면 좋아요."

3. 사용 순서, 축복받은 휘장 먼저 그다음 제련

속성 제련은 축복받은 휘장을 먼저 만든 뒤에 하는 게 안전한데, 축복받은 휘장을 만들면 재료로 쓴 휘장의 속성 제련 효과가 전부 삭제되기 때문입니다.

  1. 같은 휘장 2개로 축복받은 휘장을 만든다(공식 공지 기준 +3 이상)
  2. 축복받은 휘장에 속성 제련을 한다
  3. 다시 제련하면 기존 옵션을 지우고 새 옵션으로 덮어쓴다

📷 〔사진 자리 3〕 축복받은 휘장 속성 제련 화면 — 네이버에서 직접 업로드

└ 캡션 추천: "보시는 것처럼 축복받은 휘장을 먼저 만들고 나서 이 화면으로 오시면 됩니다."

축복받은 지휘관의 휘장은 +6부터 '레벨에 의한 스킬 성공 확률 1단계 상승'(+7은 2단계)이 붙고 +7부터 스턴 시간 감소(1초)가 더해집니다. 축복받은 사냥꾼의 휘장은 +6부터 확률 대미지 리덕션, +7부터 '발동: 미티어 스트라이크'가 붙으니 이쪽도 같이 보고 만드세요.

▶ 순서 한 줄 요약 선택 상자(주화 40개) → 코어 1종 선택 → 축복받은 휘장 제작 → 속성 제련 → 마음에 안 들면 재제련

제련 옵션은 인챈트 단계별 확률로 붙고, 종류는 이렇습니다.

  • 속성 치명타, 속성 치명타 저항
  • 속성 추가 대미지, 속성 대미지 리덕션
  • 속성 저항, 속성 관통 등

휘장 강화도에 따라 붙는 옵션 그룹도 갈립니다.

4. 4속성 한눈에, 이그니스ㆍ운디네ㆍ실프ㆍ클레이

속성 코어는 이그니스(불), 운디네(물), 실프(바람), 클레이(땅) 4종이고, 공지에서 확인되는 차이는 제련 속성이 불ㆍ물ㆍ바람ㆍ땅으로 갈린다는 점입니다. 속성 관통은 제련 때 확률로 붙는 6종 옵션 중 하나라서, 코어를 쓴다고 그 속성 관통이 꼭 붙는 건 아니에요.

📷 〔사진 자리 5〕 코어 4종 툴팁 비교 — 네이버에서 직접 업로드

└ 캡션 추천: "코어 4종 툴팁을 같은 배율로 나란히 놓은 화면입니다."

이 4종은 요정 숲 방어전의 '정령의 가호'(파티장이 이그니스ㆍ운디네ㆍ실프ㆍ클레이 중 선택)와 이름이 같고, 방어전에서는 속성 상성이 PvE 이득과 PvP 우위에 관여한다고 해요. 다만 휘장 코어와 이 정령이 직접 이어진다는 규칙은 확인하지 못했습니다. 이름이 같다고 정령에 맞춰 고르면 된다고는 단정하기 어려워요.

5. 어느 속성이 추천? 정답은 없고 기준만 있다

제가 확인한 범위에서는 어느 속성이 제일 낫다는 정답이 공식 공지(인벤 전재본 기준)에도, 유저 정보글에도 없었습니다.

아래는 확인된 사실이 아니라 코어 기능에서 읽은 제 의견이고, 관통이 붙었을 때 기준입니다. 관통이 상대의 같은 속성 저항을 깎는 구조니까, 고르는 기준도 '누구를 상대하느냐'에서 나올 수밖에 없다고 봅니다.

내 상황제 의견
자주 가는 사냥터가 정해져 있다그 몬스터의 속성 저항부터 살펴보고, 저항이 낮은 속성 쪽 관통이 증폭 구간에 닿기 쉬울 것 같아요
PvP 상대가 정해져 있다상대 캐릭터의 속성 저항을 보고 같은 논리로 고르세요
아직 기준이 없다코어를 고르기 전에 상대할 곳부터 정하세요

코어는 한 번에 1종만 고르는 구조라, 관통이 붙더라도 고른 속성 하나에만 해당해요. 상대가 그 속성 저항을 두껍게 두르고 있으면 관통이 저항을 넘기 어려울 수 있으니, '무슨 속성이 강하냐'보다 '내 상대가 어느 속성에 허술하냐'를 먼저 묻는 게 맞아 보입니다.

참고로 예전 무기 속성 인챈트 기사에는 물>불>땅>바람>물 상성이 있었는데요, 이건 구형 무기 속성 기준이고 휘장 코어가 같은 상성이라고 확인된 바는 없습니다. 그대로 대입하진 마세요. 주인장이라면 코어 고르기 전에 자주 가는 사냥터 몬스터 이름부터 적어 볼 것 같네요 ㅋㅋ

6. 헷갈리기 쉬운 실수와 아직 모르는 것

  • 속성 제련을 먼저 하고 축복받은 휘장을 만들면 제련 효과가 전부 사라집니다
  • 다시 제련하면 기존 옵션이 덮어써지니, 마음에 드는 옵션이 붙었다면 재제련 전에 한 번 더 고민하세요
  • 3그룹 옵션은 +7 이상 휘장에서만 확률로 붙습니다
  • 속성 제련은 강화 UI에서 하고 속성 코어(휘장) 1개가 필요합니다(공식 공지 기준)
  • 코어 이름이 방어전 정령과 같다고 해서 정령 속성에 맞춰 고르는 건 근거가 없으니 조심하세요(직접 연동은 확인되지 않았어요)

아직 모르는 건 옵션별 수치와 확률, 그룹별 옵션 목록, 몬스터별 속성 저항, 4종의 속성 외 고유 효과, 지금도 시즌 상점에서 이 상자를 파는지예요. 공지와 정보글에 나와 있지 않아서 이 글에는 적지 않았고, 새로 나오면 추후 정리해서 알려드릴게요.

핵심만
순서는 축복받은 휘장 먼저, 속성 제련은 그다음이고, 4종 중에서는 상대할 대상의 저항 속성을 기준으로 고르는 게 제 의견입니다(관통이 붙었을 때 기준). 6월 24일 패치 기준이에요.
