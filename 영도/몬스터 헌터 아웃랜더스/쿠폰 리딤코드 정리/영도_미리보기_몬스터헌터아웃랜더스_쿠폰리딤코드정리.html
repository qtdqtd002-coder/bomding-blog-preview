2. 쿠폰 입력 방법, 이벤트 센터 코드 교환

코드는 게임 안 이벤트 센터를 열고 코드를 넣는 칸에 입력하면 돼요. 보상은 우편에서 확인하는 흐름이고요.

이벤트 센터 열기, 코드 칸 찾기, 입력, 보상 확인 네 단계예요.

  • 이벤트 센터 열기: 게임 메인 화면에서 이벤트 센터를 열어요.
  • 코드 칸 찾기: 이벤트 센터 안에서 코드를 넣는 칸을 찾아요.
  • 입력 후 확인: 코드를 입력칸에 넣고 확인 버튼을 눌러요. 직접 치는 것보다 복사해서 붙여넣는 쪽이 오타가 없어요.
  • 보상 확인: 정리글에는 보상이 우편으로 온다고 적혀 있어요. 우편함에 들어오면 열어서 받아 두세요.

game8 같은 해외 정리글은 공지 아이콘을 누른 뒤 코드 입력 페이지로 가라고 적었고, 디시 글은 이벤트 센터의 코드 교환창에 넣으라고 해요. 메뉴 이름은 정리글마다 달라서 코드 교환 등으로 적혀 있는데요, 화면에서 코드를 넣는 칸을 찾는다고 생각하시면 돼요.

입력창에 코드를 붙여넣고 확인을 누르는 자리예요.

코드는 소문자 그대로 넣는데요, 앞뒤에 공백이 붙지 않았는지도 같이 보세요.

이벤트 센터가 안 열리면 모험 랭크를 올려야 한다고 정리글들이 적었어요. 초반 모험 랭크 5라고 쓴 곳이 많더라고요.

상황에 따라 순서를 이렇게 잡으면 편해요.

이벤트 센터가 열려 있으면 mho1029부터 넣어 보세요. 방송에서 안내됐다고 정리된 코드라 제일 먼저 넣어 볼 만해요. 아직 안 열렸다면 코드를 메모만 해 두고 열린 뒤에 넣으시고요, 입력칸이 이벤트 센터 안에 있으니 센터가 열려야 넣을 수 있거든요. mhogohunt는 mho1029가 들어간 걸 확인한 다음에 시도하세요. 커뮤니티 정리 코드라 안 먹혀도 이상하지 않은데요, 그래야 입력 방법이 틀린 건지 구분하기 쉬워져요.

3. 코드별 보상과 확인 상태

  • mho1029: 인벤 팟벤 정리글(10/28)이 ‘한국 방송에서 안내한 쿠폰 코드’로 적었는데요, 한국 공식 유튜브 방송도 같은 날 올라와 있어요. 다만 영상에서 코드가 실제로 나오는 장면은 제가 직접 보지는 못했어요. 10월 29일 후속 정리글도 같은 코드를 게임 내 이벤트 센터에서 입력하라고 적었어요.
  • mhogohunt: game8, 디시, 게임위드 등 여러 정리글의 보상이 서로 같아요. 다만 처음 나온 곳은 알 수 없어서, mho1029만큼 믿고 넣기에는 조심스러워요.

공식 라운지 공지에는 아직 쿠폰이나 코드 안내가 올라오지 않았어요. 11/4에 공개된 11월 이벤트 캘린더에도 코드 칸은 없었고요.

참고로 famitsumho2026처럼 해외판 전용으로 적힌 코드도 돌아다니는데요, 한국 서버에서 되는지는 아직 알려진 게 없어서 표에는 올리지 않았어요.

4. 코드가 안 먹힐 때 체크

코드가 안 먹히면 이벤트 센터가 열렸는지, 입력한 문자가 맞는지, 이미 쓴 코드인지 순서대로 보세요.

이벤트 센터 열림 여부는 메뉴 자체가 보이는지로 알 수 있어요. 안 보이면 아직 열리지 않은 거예요. 입력 문자는 소문자 그대로인지, 앞뒤 공백이나 한글 자판 상태가 섞이지 않았는지 보시고요. 한 번 쓴 코드는 다시 안 되는 경우가 많고, 종료일 안내도 아직 없어서 어느 날 갑자기 끝났을 수도 있어요.

서버 지역도 확인하세요. 한국판은 가레나가, 글로벌판은 글로벌 공식 사이트 쪽 레벨 인피니트가 운영하는 별개 앱이라 해외 사이트의 코드가 한국판에 안 들어갈 수 있어요.

5. 코드 말고 우편으로 오는 선물과 구분

코드는 내가 직접 입력해서 받는 보상이고, 우편 선물은 입력 없이 우편함에 자동으로 들어오는 보상이에요.

보시는 것처럼 입력이 필요한지가 제일 큰 차이예요.

11월 2일 마켓 1위 기념 선물(루타 코인 ×1,500, 제니 ×1,000,000)이 우편 지급형이에요. 공식 라운지 공지 기준으로 12월 2일 23:59까지이고, 코드 칸에 넣을 필요가 없어요. 쿠폰이라는 말이 겹쳐서 헷갈리는 분이 많을 것 같은데요, 자세한 건 「몬스터헌터 아웃랜더스 쿠폰 코드 없이 우편으로 받는 법, 마켓 1위 기념 루타 코인 1500 제니 100만 12월 2일까지」 글에 정리했어요.

6. 새 코드는 어디서 확인하나

새 코드는 공식 라운지 공지, 가레나 한국 공지, 공식 유튜브 순서로 확인하는 게 안전해요.

  • 공식 라운지 공지: 이벤트 공지가 올라오는 곳이에요.
  • 가레나 한국 공지(mho.garena.com/kr): 커뮤니티 이벤트 규약에 ‘게임 내 보상은 게임 내 우편 또는 교환 코드를 통해 지급됩니다’라는 문구가 있어요. 교환 코드 경로가 있다는 공식 문구지만 개별 코드 목록은 아니에요.
  • 공식 유튜브 방송: mho1029가 안내됐다고 정리된 곳이 이 방송이에요.

보상과 출처 없이 코드만 줄줄이 올려 둔 모음 페이지는 거르세요. 코드만 줄줄이 올려 둔 곳 중에는 공식 안내나 커뮤니티 정리에도 없는 코드를 ‘사용 가능’이라고 적어 둔 데도 있더라고요.

2. 쿠폰 입력 방법, 이벤트 센터 코드 교환

코드는 게임 안 이벤트 센터를 열고 코드를 넣는 칸에 입력하면 돼요. 보상은 우편에서 확인하는 흐름이고요.

📷 〔그림 자리 2〕 코드 입력 순서 도해: 이벤트 센터 열기 → 코드 넣는 칸 찾기 → 코드 붙여넣고 확인 → 우편에서 보상 확인 (미리보기의 도해를 이미지로 복사해 업로드)

└ 캡션 추천: "이벤트 센터 열기, 코드 칸 찾기, 입력, 보상 확인 네 단계예요."

  • 이벤트 센터 열기: 게임 메인 화면에서 이벤트 센터를 열어요.
  • 코드 칸 찾기: 이벤트 센터 안에서 코드를 넣는 칸을 찾아요.
  • 입력 후 확인: 코드를 입력칸에 넣고 확인 버튼을 눌러요. 직접 치는 것보다 복사해서 붙여넣는 쪽이 오타가 없어요.
  • 보상 확인: 정리글에는 보상이 우편으로 온다고 적혀 있어요. 우편함에 들어오면 열어서 받아 두세요.

game8 같은 해외 정리글은 공지 아이콘을 누른 뒤 코드 입력 페이지로 가라고 적었고, 디시 글은 이벤트 센터의 코드 교환창에 넣으라고 해요. 메뉴 이름은 정리글마다 달라서 코드 교환 등으로 적혀 있는데요, 화면에서 코드를 넣는 칸을 찾는다고 생각하시면 돼요.

코드는 소문자 그대로 넣는데요, 앞뒤에 공백이 붙지 않았는지도 같이 보세요.

이벤트 센터가 안 열리면 모험 랭크를 올려야 한다고 정리글들이 적었어요. 초반 모험 랭크 5라고 쓴 곳이 많더라고요.

상황에 따라 순서를 이렇게 잡으면 편해요.

이벤트 센터가 열려 있으면 mho1029부터 넣어 보세요. 방송에서 안내됐다고 정리된 코드라 제일 먼저 넣어 볼 만해요. 아직 안 열렸다면 코드를 메모만 해 두고 열린 뒤에 넣으시고요, 입력칸이 이벤트 센터 안에 있으니 센터가 열려야 넣을 수 있거든요. mhogohunt는 mho1029가 들어간 걸 확인한 다음에 시도하세요. 커뮤니티 정리 코드라 안 먹혀도 이상하지 않은데요, 그래야 입력 방법이 틀린 건지 구분하기 쉬워져요.

  • mho1029: 인벤 팟벤 정리글(10/28)이 ‘한국 방송에서 안내한 쿠폰 코드’로 적었는데요, 한국 공식 유튜브 방송도 같은 날 올라와 있어요. 다만 영상에서 코드가 실제로 나오는 장면은 제가 직접 보지는 못했어요. 10월 29일 후속 정리글도 같은 코드를 게임 내 이벤트 센터에서 입력하라고 적었어요.
  • mhogohunt: game8, 디시, 게임위드 등 여러 정리글의 보상이 서로 같아요. 다만 처음 나온 곳은 알 수 없어서, mho1029만큼 믿고 넣기에는 조심스러워요.

4. 코드가 안 먹힐 때 체크

코드가 안 먹히면 이벤트 센터가 열렸는지, 입력한 문자가 맞는지, 이미 쓴 코드인지 순서대로 보세요.

이벤트 센터 열림 여부는 메뉴 자체가 보이는지로 알 수 있어요. 안 보이면 아직 열리지 않은 거예요. 입력 문자는 소문자 그대로인지, 앞뒤 공백이나 한글 자판 상태가 섞이지 않았는지 보시고요. 한 번 쓴 코드는 다시 안 되는 경우가 많고, 종료일 안내도 아직 없어서 어느 날 갑자기 끝났을 수도 있어요.

서버 지역도 확인하세요. 한국판은 가레나가, 글로벌판은 글로벌 공식 사이트 쪽 레벨 인피니트가 운영하는 별개 앱이라 해외 사이트의 코드가 한국판에 안 들어갈 수 있어요.

5. 코드 말고 우편으로 오는 선물과 구분

코드는 내가 직접 입력해서 받는 보상이고, 우편 선물은 입력 없이 우편함에 자동으로 들어오는 보상이에요.

11월 2일 마켓 1위 기념 선물(루타 코인 ×1,500, 제니 ×1,000,000)이 우편 지급형이에요. 공식 라운지 공지 기준으로 12월 2일 23:59까지이고, 코드 칸에 넣을 필요가 없어요. 쿠폰이라는 말이 겹쳐서 헷갈리는 분이 많을 것 같은데요, 자세한 건 「몬스터헌터 아웃랜더스 쿠폰 코드 없이 우편으로 받는 법, 마켓 1위 기념 루타 코인 1500 제니 100만 12월 2일까지」 글에 정리했어요.

6. 새 코드는 어디서 확인하나

새 코드는 공식 라운지 공지, 가레나 한국 공지, 공식 유튜브 순서로 확인하는 게 안전해요.

  • 공식 라운지 공지: 이벤트 공지가 올라오는 곳이에요.
  • 가레나 한국 공지(mho.garena.com/kr): 커뮤니티 이벤트 규약에 ‘게임 내 보상은 게임 내 우편 또는 교환 코드를 통해 지급됩니다’라는 문구가 있어요. 교환 코드 경로가 있다는 공식 문구지만 개별 코드 목록은 아니에요.
  • 공식 유튜브 방송: mho1029가 안내됐다고 정리된 곳이 이 방송이에요.

보상과 출처 없이 코드만 줄줄이 올려 둔 모음 페이지는 거르세요. 코드만 줄줄이 올려 둔 곳 중에는 공식 안내나 커뮤니티 정리에도 없는 코드를 ‘사용 가능’이라고 적어 둔 데도 있더라고요.
