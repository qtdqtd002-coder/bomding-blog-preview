## 2. 🔴 헤지 동형 반복 — "~것 같아요/것 같습니다" 8회 (2026-07-19 현안 재발)
2,057자 산문에 "것 같아요" 5 + "것 같습니다" 3 = 8회(약 257자당 1회). D-2 변주 레지스터가 07-01부터 10회 이상 연속으로 "~것 같아요"를 다음 글 회피 과용후보로 지정해 왔는데 그대로 재발.
인접 2연속 사례:
- "…같이 챙겨두시면 좋을 것 같아요." → "…부담 없이 들어가기 좋을 것 같습니다."
- "…정리가 되는 것 같아요." → "…미리 예약해두시면 좋을 것 같습니다."
처방: 절반 이상을 봄딩 어미로 교체 — ~네요/~거든요/~잖아요/~답니다/~죠, 단정형("괜찮아요"·"편해요"), "~하시면 되겠습니다"(팁 끝맺음 정형구).

## 4. 🟡 표-직후 동어반복 (07-18 아란 환류 2번 재발)
