도깨비의세계 서버 추천 전에 볼 서버 선택 구조, 같은 서버는 같은 편이고 거래소는 매칭 서버끼리

봄딩2026.10.07· 게임

도깨비의세계 서버 선택 화면에 서버가 30개나 떠 있으면 어디부터 눌러야 할지 멈칫하게 되더라고요ㅎㅎ 정식 출시(10월 8일 목요일 11시)를 앞둔 지금은 '이 서버가 제일 낫다'고 단정할 수는 없어요. 대신 서버를 하나 고르면 같은 편이 정해지고, 낙화의 전장과 차원점령전에서는 서버 3개가 한 묶음으로 매칭되며, 그 묶음이 거래소 그룹까지 정한다는 구조는 공지에 또렷하게 나와 있습니다.

서버 얘기가 공지 몇 곳에 나뉘어 있어서, 이번엔 서버 이름을 비교하는 대신 서버 하나에 무엇이 묶여 있는지를 한 흐름으로 이어서 풀어볼게요. 10월 7일 기준 내용이라 출시 뒤에는 달라질 수 있어요.

서버는 몇 개고, 캐릭터는 서버마다 몇 개 만드나요?

서버는 모두 30개예요.

  • 이름은 몽련·해월·괴량·아산·홍미희·강이태·소운·공월아·무이·묘롱까지 열 개고, 각각 1~3번으로 나뉘어요
  • 계정당 캐릭터는 서버마다 1개씩만 만들 수 있어요
  • 캐릭터명은 전 서버를 통틀어 하나라서 다른 서버에서도 같은 이름은 못 써요
  • 선점해 둔 서버와 캐릭터명은 선점 기간이 끝나면서 확정되어 바꿀 수 없고, 선점할 때 쓴 카카오 계정으로 로그인해야 쓸 수 있어요
  • 선점은 카카오 사전예약 계정 1개당 1번만 진행할 수 있었어요

여기까지가 고르기 전의 기본 규칙이고, 서버가 같은 편과 거래소 그룹을 정해준다는 점이 다음 이야기입니다.

PvP에서는 누구랑 같은 편이고, 누구랑 붙나요?

같은 서버 도사끼리는 같은 편이라 서로 공격할 수 없고, 낙화의 전장과 차원점령전에서는 서버 3개가 한 묶음으로 매칭돼 겨뤄요.

서버를 정한다는 건 같은 편이 될 도사님들을 정하는 일이고, 상대 서버는 내가 고르는 게 아니라 매칭이 정합니다. 서버 3개 매칭은 낙화의 전장과 차원점령전에 한정되고, 신기쟁탈전과 미혹의 정원은 문파끼리 붙는 PvP예요. 콘텐츠별 차이는 아래 같이 보기에 걸어 둔 PvP 4종 총정리 글에 풀어 뒀어요.

시즌이 끝나면 서버 묶음은 어떻게 바뀌나요?

시즌은 2주 단위로 돌고, 끝나면 매칭 서버가 비슷한 등급의 서버 3개로 다시 섞여요.

묶음이 바뀌어도 내 서버는 그대로고, 같이 묶이는 서버만 달라져요.

섞이는 건 상대 서버 쪽이라서 레벨이나 장비 같은 캐릭터 성장은 그대로 이어지고, 낙화의 전장 점수만 초기화돼요. 이번 시즌에 만난 서버가 다음 시즌에도 같은 묶음이라는 보장은 없어요.

거래소는 어떻게 묶이고, 셔플되면 어떻게 되나요?

거래소는 매칭되는 서버끼리 같은 그룹을 공유하고, 시즌이 끝나 서버가 다시 섞이면 거래소 그룹도 함께 바뀌어요.

거래소는 귀속되지 않은 아이템을 등록해 다른 도사님께 금전으로 파는 곳이고, 영석으로 산 상품도 포장 상태로 올릴 수 있습니다. 금전 자체가 도사님들이 콘텐츠로 모아 거래소에서 돌리는 재화예요. 거래소에서 마주치는 물건과 사람은 내 서버만이 아니라 같이 묶인 서버들 몫이라, 묶음이 달라지면 보이는 매물도 달라질 수 있어요. 그룹이 바뀌었을 때 시세나 수요가 흔들리는 일을 막으려고, 공지에는 일정 시간 구매할 수 없게 하는 시스템을 마련했다고 적혀 있습니다. 이 글에서는 등록 방법이나 수수료 같은 이용법 대신 구조만 짚었습니다.

📷스샷 4: 거래소 화면 — 매물 목록이 보이는 장면
📸 직접 촬영 권장 — 거래소에 들어가 매물 목록이 보이는 첫 화면. 시즌이 바뀐 직후에 같은 화면을 한 번 더 찍어두면 그룹이 바뀐 걸 비교하기 좋아요.

지금 보이는 매물이 어느 서버 묶음의 것인지가 시즌마다 달라질 수 있어요.

서버를 고를 때 따져볼 건 뭐가 있나요?

서버를 고를 땐 인구를 따지기보다 같이 할 사람과 같은 서버로 모일 수 있는지부터 보시는 게 좋아요.

이런 상황이라면서버와 얽히는 규칙
친구와 레이드를 같이 돌고 싶어요레이드는 매칭으로 다른 서버 도사님과도 할 수 있지만, 특정 친구를 지정해 같이 하는 기능은 아직 지원하지 않아요(검토 중)
친구가 다른 서버예요같은 편이 아니라서, 같은 매칭 묶음에 들어가는 시즌에는 서로 맞붙는 쪽으로 보여요
친구와 같은 거래소를 쓰고 싶어요같은 서버끼리는 늘 같은 그룹이고, 서버가 다르면 그 시즌에 같은 묶음일 때만 같은 그룹으로 보여요

저라면 서버 숫자보다 같이 달릴 사람이 어디 모이는지를 먼저 볼 것 같아요. 매칭 상대와 거래소 그룹은 서버를 고른 뒤에도 내 선택 밖에서 2주마다 정해지니까요.

그래서 어느 서버를 추천하냐고요?

지금은 어느 서버가 좋다고 말씀드리기 어려워요. 비슷한 등급을 어떤 세부 기준으로 가르는지, 서버별 인구는 공지에 나와 있지 않기 때문이에요.

  • 서버별 인구와 활성도
  • '비슷한 등급'을 어떤 세부 기준으로 가르는지
  • 시즌 1에서 어느 서버끼리 처음 묶이는지

확인 위치: 출시 후 인게임 서버 선택 화면, 공식 포럼 공지 · 확인되면 이 자리에 값을 채워주세요.

이 세 가지는 서버 선택에 곧바로 영향을 주는 값이라, 출시 뒤 서버 인구 분포와 첫 매칭 결과가 보이기 시작하면 이 글도 손볼 예정이에요~

자주 묻는 질문

Q. 셔플되면 거래소에 올려둔 물건은 어떻게 되나요?
그룹이 바뀐 직후의 구매 제한은 앞에서 말씀드린 대로이고, 등록해 둔 매물과 정산이 새 그룹으로 어떻게 이어지는지는 공개 전이에요.

Q. 다른 서버에 새 캐릭터를 만들 수 있나요?
네, 정식 론칭 이후엔 다른 서버에도 새 캐릭터를 만들어 쓸 수 있다고 해요. 다만 그 서버에서 새 캐릭터를 만들 수 있는 상태여야 하고, 원하는 캐릭터명을 이미 다른 도사님이 쓰고 있으면 안 돼요. 반드시 선점한 서버에서만 이용해야 하는 건 아니라는 점도 같이 안내됐어요. 서버마다 1개씩이라는 규칙은 그대로이고, 출시 후 서버 이동 정책은 공지에서 확인되지 않아요.

여기까지가 고르기 전의 기본 규칙이고, 서버가 같은 편과 거래소 그룹을 정해준다는 점이 다음 이야기입니다.

PvP에서는 누구랑 같은 편이고, 누구랑 붙나요?

같은 서버 도사끼리는 같은 편이라 서로 공격할 수 없고, 낙화의 전장과 차원점령전에서는 서버 3개가 한 묶음으로 매칭돼 겨뤄요.

서버를 정한다는 건 같은 편이 될 도사님들을 정하는 일이고, 상대 서버는 내가 고르는 게 아니라 매칭이 정합니다. 서버 3개 매칭은 낙화의 전장과 차원점령전에 한정되고, 신기쟁탈전과 미혹의 정원은 문파끼리 붙는 PvP예요. 콘텐츠별 차이는 아래 같이 보기에 걸어 둔 PvP 4종 총정리 글에 풀어 뒀어요.

시즌이 끝나면 서버 묶음은 어떻게 바뀌나요?

시즌은 2주 단위로 돌고, 끝나면 매칭 서버가 비슷한 등급의 서버 3개로 다시 섞여요.

📷 〔사진 자리 3〕 서버 3개 묶음 도식 — 시즌 중 '내 서버+서버 B·C' → 시즌 종료 재셔플 → 다음 시즌 '내 서버+서버 D·E', 거래소 그룹도 함께 변경 — 미리보기의 도식을 이미지로 받아 네이버에서 업로드

섞이는 건 상대 서버 쪽이라서 레벨이나 장비 같은 캐릭터 성장은 그대로 이어지고, 낙화의 전장 점수만 초기화돼요. 이번 시즌에 만난 서버가 다음 시즌에도 같은 묶음이라는 보장은 없어요.

거래소는 어떻게 묶이고, 셔플되면 어떻게 되나요?

거래소는 매칭되는 서버끼리 같은 그룹을 공유하고, 시즌이 끝나 서버가 다시 섞이면 거래소 그룹도 함께 바뀌어요.

거래소는 귀속되지 않은 아이템을 등록해 다른 도사님께 금전으로 파는 곳이고, 영석으로 산 상품도 포장 상태로 올릴 수 있습니다. 금전 자체가 도사님들이 콘텐츠로 모아 거래소에서 돌리는 재화예요. 거래소에서 마주치는 물건과 사람은 내 서버만이 아니라 같이 묶인 서버들 몫이라, 묶음이 달라지면 보이는 매물도 달라질 수 있어요. 그룹이 바뀌었을 때 시세나 수요가 흔들리는 일을 막으려고, 공지에는 일정 시간 구매할 수 없게 하는 시스템을 마련했다고 적혀 있습니다. 이 글에서는 등록 방법이나 수수료 같은 이용법 대신 구조만 짚었습니다.

서버를 고를 때 따져볼 건 뭐가 있나요?

서버를 고를 땐 인구를 따지기보다 같이 할 사람과 같은 서버로 모일 수 있는지부터 보시는 게 좋아요.

이런 상황이라면서버와 얽히는 규칙
친구와 레이드를 같이 돌고 싶어요레이드는 매칭으로 다른 서버 도사님과도 할 수 있지만, 특정 친구를 지정해 같이 하는 기능은 아직 지원하지 않아요(검토 중)
친구가 다른 서버예요같은 편이 아니라서, 같은 매칭 묶음에 들어가는 시즌에는 서로 맞붙는 쪽으로 보여요
친구와 같은 거래소를 쓰고 싶어요같은 서버끼리는 늘 같은 그룹이고, 서버가 다르면 그 시즌에 같은 묶음일 때만 같은 그룹으로 보여요

저라면 서버 숫자보다 같이 달릴 사람이 어디 모이는지를 먼저 볼 것 같아요. 매칭 상대와 거래소 그룹은 서버를 고른 뒤에도 내 선택 밖에서 2주마다 정해지니까요.

그래서 어느 서버를 추천하냐고요?

지금은 어느 서버가 좋다고 말씀드리기 어려워요. 비슷한 등급을 어떤 세부 기준으로 가르는지, 서버별 인구는 공지에 나와 있지 않기 때문이에요.

  • 서버별 인구와 활성도
  • '비슷한 등급'을 어떤 세부 기준으로 가르는지
  • 시즌 1에서 어느 서버끼리 처음 묶이는지

이 세 가지는 서버 선택에 곧바로 영향을 주는 값이라, 출시 뒤 서버 인구 분포와 첫 매칭 결과가 보이기 시작하면 이 글도 손볼 예정이에요~

자주 묻는 질문

Q. 셔플되면 거래소에 올려둔 물건은 어떻게 되나요?
그룹이 바뀐 직후의 구매 제한은 앞에서 말씀드린 대로이고, 등록해 둔 매물과 정산이 새 그룹으로 어떻게 이어지는지는 공개 전이에요.

Q. 다른 서버에 새 캐릭터를 만들 수 있나요?
네, 정식 론칭 이후엔 다른 서버에도 새 캐릭터를 만들어 쓸 수 있다고 해요. 다만 그 서버에서 새 캐릭터를 만들 수 있는 상태여야 하고, 원하는 캐릭터명을 이미 다른 도사님이 쓰고 있으면 안 돼요. 반드시 선점한 서버에서만 이용해야 하는 건 아니라는 점도 같이 안내됐어요. 서버마다 1개씩이라는 규칙은 그대로이고, 출시 후 서버 이동 정책은 공지에서 확인되지 않아요.
