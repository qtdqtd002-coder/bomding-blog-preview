PixAI 츠바키3업데이트 얼리액세스 후기 AI캐릭터만들기 LoRA사용법 정리

봄딩2026.08.26· 정보

본 포스팅은 해당 업체로부터 원고료를 지원받아 솔직하게 작성된 후기입니다. 얼마 전에 PixAI(픽스AI) 쪽에서 연락을 받고, 이번에 새로 나온 모델 '츠바키.3(Tsubaki.3)'를 얼리 액세스가 열렸다는 소식을 듣고, 어떤 순서로 쓰는 건지부터 공식 안내를 짚어가며 정리해봤어요. 먼저 결론부터 정직하게 말씀드리면, 지금은 아무나 바로 쓸 수 있는 단계가 아니라 사전 신청으로 선정된 이용자부터 순차로 체험 중인 얼리 액세스 상태고, 정식 출시일은 아직 공지되지 않았거든요. 그 전제를 깔고, 실제로 화면에서 눌러야 하는 순서 그대로 프롬프트 입력부터 스타일 LoRA 적용까지 후기 삼아 정리해볼게요.

츠바키.3, 뭐가 그렇게 달라졌길래 화제인가요

츠바키.3는 텍스트 렌더링·만화 제작 효율·다수 캐릭터 표현 이 세 가지를 끌어올린 PixAI의 애니메이션 특화 모델이에요. 국내 IT매체도 이 세 가지를 이번 츠바키.3의 핵심 개선점으로 짚었어요. 눌러보기 전에 챙겨두면 좋을 특징은 이렇습니다.

  • 텍스트 렌더링 향상 — 프롬프트에 글자가 들어가는 그림(포스터·표지·말풍선 등)에서 의도한 문구가 더 정확하게 나온다고 해요.
  • 만화 제작 효율성 — 캐릭터와 구도의 일관성이 좋아져서 여러 컷·장면을 이어 만드는 작업이 한결 수월해졌다고 합니다.
  • 다수 캐릭터 표현 — 인물 두 명 이상이 한 화면에 들어가는 장면에서도 붕괴 없이 안정적으로 나온다는 점을 특히 강조하더라고요.
  • 여기에 더해 색상을 직접 지정하는 'Color Palette' 기능도 이번에 같이 얼리 액세스로 풀렸어요.

지금 바로 신청하면 다 열리는 건 아니더라고요

츠바키.3는 2026년 8월 12일부터 얼리 액세스가 시작됐지만, 사전 신청자 중 선정된 이용자만 순차로 체험할 수 있는 단계예요. 전체 이용자에게 완전히 풀린 게 아니라서, 신청하신 분들도 선정 여부를 기다리셔야 하는 단계예요. 위에서 말씀드린 Color Palette 기능 역시 이 테스터 범위 안에서만 열려 있고요. 정식 출시일은 이 글을 쓰는 시점(2026.08.26 기준)까지 별도 공지가 없어서, 궁금하신 분은 PixAI 바로가기로 들어가서 공식 블로그 소식을 직접 확인해보시는 게 제일 정확할 것 같아요.

프롬프트는 이렇게 입력하면 돼요

프롬프트 작성 방식이 딱히 어렵진 않았어요. 공식 가이드가 안내하는 순서를 그대로 따르면, 주인공과 행동을 먼저 쓰고 → 외형을 구체적으로 묘사한 다음 → 장소와 빛 설정을 붙이고 → 주변과의 관계까지 얹으면 얼추 문장 하나가 완성되는 구조더라고요. 영어 기준 30~150단어가 권장 분량이라는데, 프롬프트 도우미가 자동으로 다듬어주고 한국어 입력도 지원해서 부담 없었어요.

스타일 LoRA는 이런 순서로 적용해요

제가 제일 흥미롭게 본 건 스타일 LoRA였어요. LoRA 사용법이 생각보다 간단해서, 자캐 만들기나 최애캐 그림처럼 AI 캐릭터 만들기를 시도해보고 싶은 분이라면 눈여겨볼 만한데, 순서는 대략 이렇더라고요.

  • 기반 모델 확인 — 마켓에서 LoRA를 고를 때 표기된 기반 모델이 지금 쓰는 생성 모델과 맞는지부터 확인해요(안 맞으면 효과가 아예 안 먹히는 경우가 많다고 해요).
  • 트리거 워드 입력 — LoRA 상세 페이지에 적힌 트리거 워드를 프롬프트에 그대로 넣어야 스타일이 실제로 반영돼요.
  • 강도(weight) 조절 — 캐릭터 LoRA는 0.7~0.8, 스타일 LoRA는 0.6 정도가 무난하고, 둘을 같이 걸 때는 스타일 쪽을 0.5로 낮추면 충돌이 덜하다고 해요.

새로 생긴 Color Palette 기능은 이런 식이에요

이번에 같이 열린 Color Palette 기능은 색상을 헥스코드와 비율로 직접 지정할 수 있는 게 핵심이에요. Overall(전체)·Character(캐릭터)·Background(배경) 세 탭에 각각 적용해요.

  • 프리셋 팔레트 — 라이브러리에 있는 팔레트를 그대로 골라 써요.
  • 헥스코드 직접 입력 — 원하는 색상 코드를 직접 넣어 지정해요.
  • 이미지에서 색상 추출 — 갖고 있는 이미지에서 색을 뽑아와 적용해요.

PixAI가 어떤 곳인지 짧게 짚고 갈게요

사실 지난번 '아이스바 페스티벌' 이벤트 소개 글에서 PixAI를 한 번 다뤄드린 적이 있는데(그 글은 발행 시 여기 링크로 연결해둘게요), 이번엔 신모델 실사용 후기로 다시 왔어요. 짧게만 짚자면 PixAI는 설치 없이 웹사이트에서 애니메이션·서브컬처 이미지를 만드는 곳이고, 프롬프트 없이도 AI 채팅 Mio.2로 요청하면 결과물이 나와요.

자주 묻는 질문

Q. PixAI는 무료로 사용할 수 있나요?
기본 기능은 무료로 체험할 수 있고, 캠페인으로 무료 크레딧을 주는 경우도 종종 있어요. 얼리 액세스로 선정되면 하루 최대 30회까지 무료로 생성해볼 수 있다고 해요.

Q. 츠바키3 선물 이벤트는 언제까지인가요?
2026년 8월 12일부터 9월 16일까지 진행되는 이벤트로, 참여하려면 지정 해시태그 #PixAITsubakiV3를 꼭 붙여야 해요. 앞서 8월 18일에 끝난 '아이스바 페스티벌'과는 완전히 다른 별개 캠페인이니 헷갈리지 않으셨으면 해요.

Q. PixAI에서 만든 이미지는 어디에 활용할 수 있나요?
프로필이나 SNS 게시용 자캐 이미지로 쓰는 경우가 많고, 이미지를 애니메이션화(영상)로 변환해 짧은 클립으로 공유하는 것도 가능해요.

프롬프트 입력부터 LoRA 적용까지 순서대로 짚어보니 확실히 손이 많이 가는 툴은 아니었어요. 정식 출시로 범위가 넓어지면 그때 결과물을 더 채워서 보여드릴게요. 관심 있으신 분들은 PixAI 바로가기에서 신청 여부부터 확인해보시길 추천드려요.

본 포스팅은 해당 업체로부터 원고료를 지원받아 솔직하게 작성된 후기입니다. 얼마 전에 PixAI(픽스AI) 쪽에서 연락을 받고, 이번에 새로 나온 모델 '츠바키.3(Tsubaki.3)'를 얼리 액세스가 열렸다는 소식을 듣고, 어떤 순서로 쓰는 건지부터 공식 안내를 짚어가며 정리해봤어요. 먼저 결론부터 정직하게 말씀드리면, 지금은 아무나 바로 쓸 수 있는 단계가 아니라 사전 신청으로 선정된 이용자부터 순차로 체험 중인 얼리 액세스 상태고, 정식 출시일은 아직 공지되지 않았거든요. 그 전제를 깔고, 실제로 화면에서 눌러야 하는 순서 그대로 프롬프트 입력부터 스타일 LoRA 적용까지 후기 삼아 정리해볼게요.

츠바키.3, 뭐가 그렇게 달라졌길래 화제인가요

츠바키.3는 텍스트 렌더링·만화 제작 효율·다수 캐릭터 표현 이 세 가지를 끌어올린 PixAI의 애니메이션 특화 모델이에요. 국내 IT매체도 이 세 가지를 이번 츠바키.3의 핵심 개선점으로 짚었어요. 눌러보기 전에 챙겨두면 좋을 특징은 이렇습니다.

  • 텍스트 렌더링 향상 — 프롬프트에 글자가 들어가는 그림(포스터·표지·말풍선 등)에서 의도한 문구가 더 정확하게 나온다고 해요.
  • 만화 제작 효율성 — 캐릭터와 구도의 일관성이 좋아져서 여러 컷·장면을 이어 만드는 작업이 한결 수월해졌다고 합니다.
  • 다수 캐릭터 표현 — 인물 두 명 이상이 한 화면에 들어가는 장면에서도 붕괴 없이 안정적으로 나온다는 점을 특히 강조하더라고요.
  • 여기에 더해 색상을 직접 지정하는 'Color Palette' 기능도 이번에 같이 얼리 액세스로 풀렸어요.

지금 바로 신청하면 다 열리는 건 아니더라고요

츠바키.3는 2026년 8월 12일부터 얼리 액세스가 시작됐지만, 사전 신청자 중 선정된 이용자만 순차로 체험할 수 있는 단계예요. 전체 이용자에게 완전히 풀린 게 아니라서, 신청하신 분들도 선정 여부를 기다리셔야 하는 단계예요. 위에서 말씀드린 Color Palette 기능 역시 이 테스터 범위 안에서만 열려 있고요. 정식 출시일은 이 글을 쓰는 시점(2026.08.26 기준)까지 별도 공지가 없어서, 궁금하신 분은 PixAI 바로가기로 들어가서 공식 블로그 소식을 직접 확인해보시는 게 제일 정확할 것 같아요.

프롬프트는 이렇게 입력하면 돼요

프롬프트 작성 방식이 딱히 어렵진 않았어요. 공식 가이드가 안내하는 순서를 그대로 따르면, 주인공과 행동을 먼저 쓰고 → 외형을 구체적으로 묘사한 다음 → 장소와 빛 설정을 붙이고 → 주변과의 관계까지 얹으면 얼추 문장 하나가 완성되는 구조더라고요. 영어 기준 30~150단어가 권장 분량이라는데, 프롬프트 도우미가 자동으로 다듬어주고 한국어 입력도 지원해서 부담 없었어요.

스타일 LoRA는 이런 순서로 적용해요

제가 제일 흥미롭게 본 건 스타일 LoRA였어요. LoRA 사용법이 생각보다 간단해서, 자캐 만들기나 최애캐 그림처럼 AI 캐릭터 만들기를 시도해보고 싶은 분이라면 눈여겨볼 만한데, 순서는 대략 이렇더라고요.

  • 기반 모델 확인 — 마켓에서 LoRA를 고를 때 표기된 기반 모델이 지금 쓰는 생성 모델과 맞는지부터 확인해요(안 맞으면 효과가 아예 안 먹히는 경우가 많다고 해요).
  • 트리거 워드 입력 — LoRA 상세 페이지에 적힌 트리거 워드를 프롬프트에 그대로 넣어야 스타일이 실제로 반영돼요.
  • 강도(weight) 조절 — 캐릭터 LoRA는 0.7~0.8, 스타일 LoRA는 0.6 정도가 무난하고, 둘을 같이 걸 때는 스타일 쪽을 0.5로 낮추면 충돌이 덜하다고 해요.

새로 생긴 Color Palette 기능은 이런 식이에요

이번에 같이 열린 Color Palette 기능은 색상을 헥스코드와 비율로 직접 지정할 수 있는 게 핵심이에요. Overall(전체)·Character(캐릭터)·Background(배경) 세 탭에 각각 적용해요.

  • 프리셋 팔레트 — 라이브러리에 있는 팔레트를 그대로 골라 써요.
  • 헥스코드 직접 입력 — 원하는 색상 코드를 직접 넣어 지정해요.
  • 이미지에서 색상 추출 — 갖고 있는 이미지에서 색을 뽑아와 적용해요.

츠바키3 선물 이벤트도 같이 진행 중이에요

츠바키.3 출시를 기념해서 '츠바키3 선물 이벤트'가 2026년 8월 12일부터 9월 16일까지 열리고 있어요(오늘 2026.08.26 기준 진행 중). 참여 방법·보상은 아래에 정리했어요. 참고로 이 이벤트는 앞서 진행됐던 '아이스바 페스티벌'과는 완전히 다른 별개 캠페인이에요 — 아이스바 페스티벌은 8월 18일 정오에 이미 끝났으니 헷갈리지 않으셨으면 해요. (이벤트 정보는 2026.08.26 기준이고, 자세한 조건은 PixAI 공식 채널에서 확인하시는 게 정확해요)

  • 참여방법 — 공식 캠페인 게시물을 인용해 작품·소감을 공유 + 지정 해시태그 #PixAITsubakiV3 필수
  • 전체 보상 — 참여자 전체가 나눠 갖는 2,500만 PixAI 크레딧 + 3만7,500엔 상당 아마존 기프트카드
  • 데일리 추첨 — 매일 10명에게 '츠바키.3 생성 카드 50매' 또는 얼리 액세스 마지막 주 이용권 중 하나 지급

무료 크레딧 이벤트니 겸사겸사 참여해보셔도 좋을 것 같아요.

PixAI가 어떤 곳인지 짧게 짚고 갈게요

사실 지난번 '아이스바 페스티벌' 이벤트 소개 글에서 PixAI를 한 번 다뤄드린 적이 있는데(그 글은 발행 시 여기 링크로 연결해둘게요), 이번엔 신모델 실사용 후기로 다시 왔어요. 짧게만 짚자면 PixAI는 설치 없이 웹사이트에서 애니메이션·서브컬처 이미지를 만드는 곳이고, 프롬프트 없이도 AI 채팅 Mio.2로 요청하면 결과물이 나와요.

자주 묻는 질문

Q. PixAI는 무료로 사용할 수 있나요?
기본 기능은 무료로 체험할 수 있고, 캠페인으로 무료 크레딧을 주는 경우도 종종 있어요. 얼리 액세스로 선정되면 하루 최대 30회까지 무료로 생성해볼 수 있다고 해요.

Q. 츠바키3 선물 이벤트는 언제까지인가요?
2026년 8월 12일부터 9월 16일까지 진행되는 이벤트로, 참여하려면 지정 해시태그 #PixAITsubakiV3를 꼭 붙여야 해요. 앞서 8월 18일에 끝난 '아이스바 페스티벌'과는 완전히 다른 별개 캠페인이니 헷갈리지 않으셨으면 해요.

Q. PixAI에서 만든 이미지는 어디에 활용할 수 있나요?
프로필이나 SNS 게시용 자캐 이미지로 쓰는 경우가 많고, 이미지를 애니메이션화(영상)로 변환해 짧은 클립으로 공유하는 것도 가능해요.

프롬프트 입력부터 LoRA 적용까지 순서대로 짚어보니 확실히 손이 많이 가는 툴은 아니었어요. 정식 출시로 범위가 넓어지면 그때 결과물을 더 채워서 보여드릴게요. 관심 있으신 분들은 PixAI 바로가기에서 신청 여부부터 확인해보시길 추천드려요.
