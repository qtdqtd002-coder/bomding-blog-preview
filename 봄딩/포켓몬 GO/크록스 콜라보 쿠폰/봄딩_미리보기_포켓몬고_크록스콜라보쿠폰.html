포켓몬고 크록스 쿠폰, 피카츄는 공개 코드·팬텀 푸린은 구매 조건

봄딩2026. 11. 17.· 게임

포켓몬고 크록스 콜라보 소식이 한국 시간 11월 17일 새벽 1시에 올라왔는데요, 쿠폰이라는 이름 때문에 헷갈리기 쉽지만 실제로는 게임 안 아바타에 입힐 의상 아이템을 받는 프로모션 코드입니다. 피카츄 의상은 코드가 그대로 공개돼 있고, 팬텀과 푸린 의상은 해당 실물 크록스를 구매해야 코드를 받는 구조예요. 입력하는 곳부터 구매 조건, 한국 가격, 사용 기한까지 한 번에 정리해 보겠습니다.

출처: Pokémon GO 공식 공지 · 크록스의 새로운 포켓몬 컬렉션 공지

포켓몬고 크록스 콜라보 의상 아이템

크록스 포켓몬 컬렉션의 의상 아이템은 게임 내 아바타를 꾸밀 수 있는 아이템으로, 전 세계에서 이용할 수 있습니다.

의상은 포켓몬 피카츄 클래식 클로그, 포켓몬 팬텀 클래식 클로그, 포켓몬 푸린 클래식 플랫폼 클로그 세 가지인데요. 푸린 쪽만 «클래식 플랫폼 클로그»라는 점만 기억해 두시면 구분이 쉬워요. 아래에서 말하는 쿠폰은 전부 이 아바타용 프로모션 코드를 가리키고, 가게에서 사는 신발과는 따로 보셔야 합니다.

피카츄 클래식 클로그 코드 입력법

피카츄 의상은 공개된 코드 [POKEMONGOxCROCSxELECTRIFYING]를 Pokémon GO Web Store에서 입력하면 받을 수 있습니다.

  1. 웹 브라우저로 Pokémon GO Web Store의 코드 사용 페이지에 들어갑니다.
  2. Pokémon GO 계정을 쓸 때와 같은 정보로 로그인합니다.
  3. 코드 [POKEMONGOxCROCSxELECTRIFYING]를 입력하면 끝입니다.

실물을 사지 않아도 되는 건 이 피카츄 코드 하나인데요, 로그인만 되면 몇 분이면 끝나는 작업이라 부담 없이 챙기기 좋은 보상이 아닌가 싶어요. 코드 안에 소문자 x가 끼어 있어서 글자를 하나하나 치다 보면 틀리기 쉬우니, 위에 적어 둔 코드를 복사해서 붙여 넣으시는 걸 추천드립니다. 결제 없이 게임 계정 하나로 해결되니 아바타 의상 꾸미는 재미를 아시는 분이라면 오늘 바로 챙겨 둘 만하다고 생각합니다.

팬텀·푸린 클래식 클로그 구매 조건과 가격

팬텀과 푸린 의상은 공식 공지에는 팬텀·푸린 코드가 따로 적혀 있지 않고, 포켓몬 팬텀 클래식 클로그와 포켓몬 푸린 클래식 플랫폼 클로그 실물을 구매하면 각각 아이템 코드를 받는 방식입니다. 크록스 코리아에서 '포켓몬'을 검색하면 해당 상품을 찾을 수 있어요.

상품가격게임 코드
포켓몬 피카츄 클래식 클로그₩124,000공개 코드 입력
포켓몬 팬텀 클래식 클로그₩124,000구매 시 제공
포켓몬 푸린 클래식 플랫폼 클로그₩129,000구매 시 제공

크록스 코리아 11월 17일 기준 · 정가

가격은 팬텀이 ₩124,000, 푸린 플랫폼이 ₩129,000이라 푸린 쪽이 조금 더 높습니다. 팬텀은 신상품으로 올라와 있어요. 저는 코드만 보고 신발을 고르기엔 가격 부담이 작지 않다고 보는 쪽이라, 피카츄 코드를 먼저 챙기고 팬텀·푸린은 신발 자체가 마음에 들 때 고려하시는 게 편하겠네요. 평소 더 좋아하는 포켓몬이 있다면 그쪽 신발을 고르는 기준으로 삼아도 괜찮을 거 같아요. 다만 푸린은 상품명이 «클래식 플랫폼 클로그»이고 피카츄·팬텀은 «클래식 클로그»라서, 구매 전에 상품명을 꼭 맞춰 보셔야 합니다.

구매 전에 이 한 가지만
한국에서 산 팬텀·푸린 실물에도 게임 코드가 지급되는지는 아직 알 수 없어요. 한국 상품 페이지에는 포켓몬 GO 코드 안내 문구가 아직 안 보이는데요, 코드를 노리고 사실 거라면 결제 전에 판매처에 코드 지급 여부부터 문의해 보시는 걸 추천드립니다.

포켓몬고 크록스 쿠폰, 할인권과 다른 점

이 쿠폰은 게임 안 아바타 아이템을 받는 코드일 뿐이고, 크록스 신발을 싸게 사는 할인 쿠폰이 아닙니다.

코드를 입력해도 실물 가격이 내려가는 일은 없고, 반대로 코드가 나오는 실물은 팬텀 클래식 클로그와 푸린 클래식 플랫폼 클로그 두 가지로 알려져 있어요. 크록스 코리아에서 파는 포켓몬 피카츄 클래식 클로그 키즈(₩79,900)는 해당이 없어 보이는데요, 코드를 노리신다면 키즈 제품은 피하셔야 합니다. 코드는 할인 쿠폰처럼 결제 화면에 넣는 번호가 아니라, 게임 계정으로 로그인한 웹 페이지에 넣는 번호라고 생각해 두시면 헷갈릴 일이 없어요.

코드 사용 기한과 입력 전 체크리스트

프로모션 코드는 2027년 12월 31일까지 사용할 수 있습니다.

기한이 2027년 말까지로 넉넉한 편이라 서두를 필요는 없는데요, 그래도 입력 전에 아래 세 가지는 미리 챙겨 두시면 좋을 거 같아요.

  • 코드 사용 페이지는 Pokémon GO 계정으로 로그인해야 쓸 수 있어요.
  • Kids 계정은 기본 설정으로 스폰서 쿠폰을 쓸 수 없어서, 보호자가 인증된 콘텐츠 권한을 줘야 합니다.
  • 코드는 대소문자가 섞여 있으니 직접 치기보다 복사해서 붙여 넣는 쪽이 오타를 줄여요.

자녀 계정으로 입력하실 분들은 두 번째 항목이 특히 걸림돌이 될 수 있는데요, 입력 화면에서 막히기 전에 보호자 설정부터 정리해 두시면 훨씬 수월합니다. 성인 계정이라면 로그인만 되면 되니 이 항목은 넘어가셔도 괜찮아요. 참고로 팬텀·푸린은 실물을 사야 코드가 생기는 구조라 구매 뒤에 입력할 수 있다는 점도 일정을 잡을 때 염두에 두시면 좋겠습니다.

자주 묻는 질문

Q. 코드가 제대로 들어갔는지 어떻게 알 수 있나요?
교환에 성공하면 추가된 아이템을 알리는 메시지가 화면에 표시됩니다. 메시지가 보이지 않으면 코드 철자와 로그인한 계정을 한 번 더 확인해 보세요.

Q. 입력했는데 오류 문구가 뜨면요?
«이 프로모션 코드가 유효하지 않거나 사용자에게 프로모션을 이용할 자격이 없습니다.»라는 문구가 나오는데요, 잘못된 코드이거나 그 계정에 자격이 없을 때 거절된다는 뜻이에요. 이 문구가 뜨면 코드 철자와 로그인한 계정부터 다시 확인해 보세요.

Q. 로그인하지 않고 코드만 입력해도 되나요?
코드 사용 페이지는 Pokémon GO 계정으로 로그인해야 쓸 수 있어요. 게임에 들어갈 때 쓰는 계정 정보와 같은 걸로 로그인하시면 됩니다. 로그인이 안 된 상태로는 이용할 수 없으니, 코드를 복사해 두고 계정 로그인부터 마친 뒤에 입력하시는 순서가 편해요.

피카츄 코드는 부담 없이 입력해 보시고, 팬텀과 푸린은 가격과 코드 지급 여부를 따져 본 뒤에 정하시면 되겠습니다. 다들 새 클로그로 아바타 꾸미시길 바랄게요.

가격은 팬텀이 ₩124,000, 푸린 플랫폼이 ₩129,000이라 푸린 쪽이 조금 더 높습니다. 팬텀은 신상품으로 올라와 있어요. 저는 코드만 보고 신발을 고르기엔 가격 부담이 작지 않다고 보는 쪽이라, 피카츄 코드를 먼저 챙기고 팬텀·푸린은 신발 자체가 마음에 들 때 고려하시는 게 편하겠네요. 평소 더 좋아하는 포켓몬이 있다면 그쪽 신발을 고르는 기준으로 삼아도 괜찮을 거 같아요. 다만 푸린은 상품명이 «클래식 플랫폼 클로그»이고 피카츄·팬텀은 «클래식 클로그»라서, 구매 전에 상품명을 꼭 맞춰 보셔야 합니다.

구매 전에 이 한 가지만
한국에서 산 팬텀·푸린 실물에도 게임 코드가 지급되는지는 아직 알 수 없어요. 한국 상품 페이지에는 포켓몬 GO 코드 안내 문구가 아직 안 보이는데요, 코드를 노리고 사실 거라면 결제 전에 판매처에 코드 지급 여부부터 문의해 보시는 걸 추천드립니다.

포켓몬고 크록스 쿠폰, 할인권과 다른 점

이 쿠폰은 게임 안 아바타 아이템을 받는 코드일 뿐이고, 크록스 신발을 싸게 사는 할인 쿠폰이 아닙니다.

코드를 입력해도 실물 가격이 내려가는 일은 없고, 반대로 코드가 나오는 실물은 팬텀 클래식 클로그와 푸린 클래식 플랫폼 클로그 두 가지로 알려져 있어요. 크록스 코리아에서 파는 포켓몬 피카츄 클래식 클로그 키즈(₩79,900)는 해당이 없어 보이는데요, 코드를 노리신다면 키즈 제품은 피하셔야 합니다. 코드는 할인 쿠폰처럼 결제 화면에 넣는 번호가 아니라, 게임 계정으로 로그인한 웹 페이지에 넣는 번호라고 생각해 두시면 헷갈릴 일이 없어요.

코드 사용 기한과 입력 전 체크리스트

프로모션 코드는 2027년 12월 31일까지 사용할 수 있습니다.

기한이 2027년 말까지로 넉넉한 편이라 서두를 필요는 없는데요, 그래도 입력 전에 아래 세 가지는 미리 챙겨 두시면 좋을 거 같아요.

  • 코드 사용 페이지는 Pokémon GO 계정으로 로그인해야 쓸 수 있어요.
  • Kids 계정은 기본 설정으로 스폰서 쿠폰을 쓸 수 없어서, 보호자가 인증된 콘텐츠 권한을 줘야 합니다.
  • 코드는 대소문자가 섞여 있으니 직접 치기보다 복사해서 붙여 넣는 쪽이 오타를 줄여요.

자녀 계정으로 입력하실 분들은 두 번째 항목이 특히 걸림돌이 될 수 있는데요, 입력 화면에서 막히기 전에 보호자 설정부터 정리해 두시면 훨씬 수월합니다. 성인 계정이라면 로그인만 되면 되니 이 항목은 넘어가셔도 괜찮아요. 참고로 팬텀·푸린은 실물을 사야 코드가 생기는 구조라 구매 뒤에 입력할 수 있다는 점도 일정을 잡을 때 염두에 두시면 좋겠습니다.

자주 묻는 질문

Q. 코드가 제대로 들어갔는지 어떻게 알 수 있나요?
교환에 성공하면 추가된 아이템을 알리는 메시지가 화면에 표시됩니다. 메시지가 보이지 않으면 코드 철자와 로그인한 계정을 한 번 더 확인해 보세요.

Q. 입력했는데 오류 문구가 뜨면요?
«이 프로모션 코드가 유효하지 않거나 사용자에게 프로모션을 이용할 자격이 없습니다.»라는 문구가 나오는데요, 잘못된 코드이거나 그 계정에 자격이 없을 때 거절된다는 뜻이에요. 이 문구가 뜨면 코드 철자와 로그인한 계정부터 다시 확인해 보세요.

Q. 로그인하지 않고 코드만 입력해도 되나요?
코드 사용 페이지는 Pokémon GO 계정으로 로그인해야 쓸 수 있어요. 게임에 들어갈 때 쓰는 계정 정보와 같은 걸로 로그인하시면 됩니다. 로그인이 안 된 상태로는 이용할 수 없으니, 코드를 복사해 두고 계정 로그인부터 마친 뒤에 입력하시는 순서가 편해요.

피카츄 코드는 부담 없이 입력해 보시고, 팬텀과 푸린은 가격과 코드 지급 여부를 따져 본 뒤에 정하시면 되겠습니다. 다들 새 클로그로 아바타 꾸미시길 바랄게요.
